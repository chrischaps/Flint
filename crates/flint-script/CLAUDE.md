# flint-script: Rhai scripting detail (moved out of the root CLAUDE.md by #755)

The root file keeps the callback list and the Rhai version gotcha. Script UI drawing: `crates/flint-player/CLAUDE.md`. Style functions (`set_entity_style`, `set_post_style`): `crates/flint-render/src/stylize/CLAUDE.md`.

- **Scripting via Rhai** -- `script` component with `.rhai` files in `scripts/`; callbacks: `on_init`, `on_update`, `on_collision`, `on_trigger_enter/exit`, `on_action`, `on_interact`, `on_draw_ui`, `on_scene_exit/enter`, `on_animation_end`, `on_sequence_cue`, `on_event` (custom events from `fire_event_data`, the engine or `ExtensionCtx::fire_event`), `on_expression(state)` (state from outside the process: `--expression-timeline <file>` on the game clock or `--expression-listen 127.0.0.1:<port>`, newline-delimited JSON read off the frame thread, loopback only; `expression()` reads the latest, any JSON object as a map with float numbers; `player_app/expression_feed.rs`, #518); `ScriptCommand` for deferred effects; `quit_game()` ends the run as the close button does (exit 0, saves flushed, `--exit-after`'s report; on the web the page's `window.flintQuit` leaves full screen and goes back to its game list, #659); `DrawCommand` for immediate-mode 2D UI; `set_scale`/`get_scale`, and `set_visible`/`is_visible` over a `visibility { visible }` component that hides an entity's subtree from every draw, shadow, light and ray target (`FlintWorld::hidden_entities`, empty and unwalked when nothing is hidden; #628). An entity setter given `-1` or a gone id warns once per script and function (`ScriptCallContext::setter_target`, #635); a new setter takes its id through it. Book's scripting page, "Script state": top-level `let`s reach callbacks, not helper `fn`s
- `ScriptCallContext` uses raw `*mut FlintWorld` -- only valid during `call_update()`/`process_events()` scope
- `on_update()` is parameterless -- use `delta_time()` API; `on_interact` checks `interactable.range` + `.enabled`
- `on_draw_ui()` ALWAYS runs even when scripts paused (pause menus need it)
