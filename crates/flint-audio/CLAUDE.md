# flint-audio: audio clock, decoding, device features (moved out of the root CLAUDE.md by #755)

Web audio (the worklet mixer): `crates/flint-player/CLAUDE.md`. The device-features note covers flint-music, flint-input-capture and flint-cli too.

- **Audio clock** (#658) -- Rhai `audio_position(entity)` (seconds into an `audio_source`'s playing sound, wrapped for a loop; -1 before it's mixed and after it ends) and `audio_output_latency()` (the browser's figure, -1 on the desktop). `AudioSync::sample_positions` runs every frame before scripts, paused or not; each source's `flint_audio::clock::PlayClock` runs kira's per-callback position on between samples. On the web the sync `watch()`es each source's voice (`Command::VoiceWatch`), the worklet's `Mixer::report` is posted every 1024 frames stamped with `currentTime` at the quantum's start (kira's position is where its last 128-frame chunk began), lands in `Link::receive_report`, and the page reads the context's `currentTime` through `Link::clock`. Demo `flint-examples/audio_clock.scene.toml`
- **Keyed sounds** (#699; `engine/keyed.rs`) -- a sound its caller names by its own `u64` key, which is how a script's `play_sound*` handle reaches `stop_sound` / `set_sound_volume`. The calls are `play_keyed` (a voice on a bus, held in `AudioEngine::keyed`), `play_keyed_at` (a placed voice: a `OneShot` with `key`, steered by `pan_oneshots`, never the old mix), `stop_keyed`, `stop_keyed_named` (every keyed sound of a resolved name, never an unkeyed one), `set_keyed_volume` (a bus voice tweens on its handle; a placed one follows a `Ramp` in `pan_oneshots`, since that sets its volume every frame), `is_keyed_playing` and `playing_keys` (every key playing now, by the same rule: a remote one-shot by its length; the player hands it to `ScriptSystem::set_sounds_playing` each frame beside the audio clock, for Rhai's `is_sound_playing`, #1000). Every fade is at least `MIN_FADE` (10 ms). A placed loop is never skipped for distance or stolen by the per-sound cap. `AudioSystem::clear` (a transition) stops the keyed loops; a keyed one-shot plays on. The worklet needs no new command: `VoiceStop` / `VoiceVolume` already exist. Tests run against `flint_audio_worklet::Mixer` and the device, plus `flint-player`'s `script_sound_tests.rs`, which reads what a scene's script sent down the link
- Decode sounds with `flint_audio::decode::decode_all` / `Decoding` (gapless, #632), not kira's `StaticSoundData::from_cursor`, which keeps a Vorbis stream's end padding (+64 to +840 frames) and so gaps a loop at every wrap. symphonia 0.5 trims that only on streams of several Ogg pages, so `Decoding` also stops a Vorbis stream at its stated length. ffmpeg trims it too, so check a loop's length through Flint, not ffmpeg. flint-music's stems still use kira's loader
- Device crates are features (#221): kira's `cpal` is flint-audio/flint-music `device` (flint-rhythm's `device` turns on flint-music's), gilrs is flint-input-capture `gamepad`, rfd is flint-cli `dialogs`; the workspace declares flint-audio/music/rhythm/input-capture/player with `default-features = false`, so a dependent names what it wants. Read pads through `flint_runtime::pad` (gilrs, or an uninhabited stand-in; `flint-runtime`'s `gamepad` feature is off by default, flint-player's and flint-input-capture's turn it on, #748), never `gilrs` directly, and file dialogs through flint-cli's `file_dialog::FileDialog`
- **`audio_source` and `audio_trigger` are read through the typed view** (ADR 0115 step 4, #685; `crates/flint-core/CLAUDE.md`) -- `world.view(id, comp::AUDIO_SOURCE)` in `AudioSync::sync_new_sources` and `read_audio_params` (every frame per synced source: the happy path takes no lock). `bus` is a `choice` over the engine's bus names (`engine.buses().names()`: `sfx`, `music` and the game's, #730); an unknown one is reported once and plays on sfx, as it always did. A source waiting for a late sound is re-read every pass and still reports once. Test without a device: `AudioEngine::silent()` + `start_remote(Link::default())` is "available" (`an_unknown_bus_and_a_wrong_volume_are_reported_once`)
- **The mixer is one trait, `engine::backend::MixerBackend`** (#730, ADR 0127) -- `AudioEngine::mixer` is a `Box<dyn MixerBackend>`: `Silent` (backend.rs), `Local` (`engine/local.rs`, kira here) or `Remote` (`engine/remote_mix.rs`, the worklet through a `Link`). Every method differing per mixer is on the trait with **no default body**, so a new one is written for all three or nothing compiles; the engine names no variant (it holds the cache, decode queue, one-shots, keyed sounds, listener place, bus table and volumes). A thing the worklet can't do yet says so in `Remote`'s body (`host` returns `Unhosted::Worklet`). The worklet's own parity: `Command::encode` and `flint_audio_worklet::Mixer::command` match every command, and `protocol::tests::every_op_reads_back` fails a command whose op the reader lacks (bump `op::LAST`)
- **Buses are data** (#730; `bus.rs`) -- `Buses`: `sfx` (0), `music` (1), then a game's from `flint.toml` `[audio.buses.<name>]` (`parent` = a bus or `master`, `volume`), numbered by name with parents first (`Buses::from_manifest`, `for_project`; errors name the file and key). `Bus` is the number (`Bus::SFX`, `Bus::MUSIC`; `Bus::Sfx`/`Music`/`from_name` deprecated for one release). `AudioEngine::set_buses(&table)`: the first table sets every starting volume, a later different one only adds buses, the same one again is a no-op (the player calls it at every `refresh_project`, `declare_audio_buses`). Each bus past the two reaches the mixer through `MixerBackend::add_bus` (the worklet: `Command::BusNew { bus, parent, db }`, refused out of order). `bus(name)`, `bus_or_sfx(name)` (warns once), `set_bus_volume_named` (script `set_bus_volume`, warns once), `bus_volume`. `set_held` quiets top-level buses only. Tests: `bus::tests`, `engine::tests::a_games_buses_reach_the_mixer_whenever_they_are_declared`, the worklet's `a_games_bus_hangs_off_its_parent_and_is_made_in_order`, flint-player `script_bus_tests.rs`
- **A sound nobody cached is found on its first play** (#975) -- `AudioEngine::set_sound_search(Some(AssetScope))` (the player sets it in `load_audio_from_world`, at every scene load and late bundle) makes `ensure_decoded`, which every play path goes through, ask `scope.resolve(AssetKind::Audio, name)` for a name neither cached nor queued, queue the file under the name as written with `Need::Asked`, then follow the queue's rule (small: decoded now; over `DECODE_NOW_BYTES`: this play skipped, front of the queue). A miss is kept in `searched_missing` until the next `set_sound_search`. `flint check` holds a script's sound strings to the same search (`check/references.rs::missing_sound`, from each scene's `AssetScope`), so the two agree: `check::references::tests::a_scripts_sound_passes_the_check_exactly_when_the_player_plays_it` asks both of each case; `engine::tests::a_sound_nobody_cached_is_found_by_the_scenes_search_when_first_played`
- **Clocked content is hosted, not handed the manager** (#730) -- `AudioEngine::host(|manager| SuiteSession::start(.., manager, ..))` / `can_host()` replace `manager_mut`: the mixer lends its kira manager for the call (`Local`) or says why not (`Unhosted::Silent`, `Unhosted::Worklet`). ADR 0017's drop order still holds
