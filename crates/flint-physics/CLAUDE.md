# flint-physics: joints (moved out of the root CLAUDE.md by #755)

The Rapier version gotcha and the fixed timestep are in the root file. A character's starting facing: `crates/flint-player/CLAUDE.md`.

- **Physics joints** (ADR 0069) -- `joint` component (hinge/prismatic/spherical/fixed) on a dynamic entity, attached to `joint.parent` or the transform parent. Bodies are placed from `get_world_matrix` and dynamic poses write back as local `position` + `rotation_quat`; unit scale is assumed on the physics chain. TOML units are degrees/metres, converted to Rapier radians at sync. Scripts drive `motor_target` via `set_joint_target` and pose rest-quaternion nodes with `rotate_local` / `set_rotation_quat` (`set_rotation` still deletes the quaternion). Bench: `examples/joint_test.scene.toml`
- **Components are read through the typed view** (ADR 0115 step 4, #685; the view itself: `crates/flint-core/CLAUDE.md`) -- `rigidbody`, `collider`, `joint`, `character_controller` via `world.view(id, comp::X)`; the allowed strings are `sync::BODY_TYPES` (`static`, `dynamic`, `kinematic`, `kinematic_position`, `kinematic_velocity`), `COLLIDER_SHAPES`, `JOINT_TYPES` (with the `slider` / `ball` aliases). An unknown one is reported once and takes the default it always took (static, box, hinge). **The defaults in these readers are the real ones**: the schema files for these components write fields under `[component.x]` with no `.fields`, so they load with no fields and their defaults are never applied; where the two differ (`rigidbody.angular_damping` reader 0.0 / schema 0.05; eye height with no `character_controller.height` reader 1.5 / schema 1.8 * 0.85 = 1.53; the schema's `body_type` values lack the two `kinematic_*` spellings) the reader's stands until someone decides. `bounds` and `sprite` (`sprite_anchor_offset_y`) are still read with `toml_util`. **A collider with no rigidbody** is never given to Rapier (`sync_to_rapier` loops over `rigidbody`); `report_lone_colliders` says so (`needs-component`) the second pass it sees one, so a script adding the two a step apart is not told off. Terrain and spline trimeshes are in `synced_entities` and are skipped. Tests: `lib.rs` (`an_unknown_body_type_warns...`, `a_collider_without_a_rigidbody_warns_once`, `an_integer_move_speed_moves_at_that_speed`, which walks a character for a second)
