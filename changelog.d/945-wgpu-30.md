### Flint is on wgpu 30 and egui 0.36: a game's own Rust and egui code moves with it (#945)
**What changed.** The engine builds on wgpu 30.0.2 and egui 0.36.2 (egui-snarl 0.12), from wgpu 23 and egui 0.30. Scenes, scripts, styles and user-style WGSL are unchanged; script HUD colours keep egui 0.30's premultiply, and text is a pixel different here and there under egui's new rasteriser. Flint's own shaders skip naga's loop bounding, which keeps ASCII as fast as before (`FLINT_SHADER_CHECKS=all` turns it back on). A Kuwahara `radius` above 32 draws at 32. `run_headless_frame`'s closure takes the root `egui::Ui`; `CurveEditor` and `GradientEditor` ids must be `Debug`.
**What to do.** A game whose own Rust calls wgpu or egui (an egui `PlayerExtension`, a `stylize::kit` style, its own window) ports to wgpu 30 and egui 0.36; #946 brings the migration note. A subtree game that builds for the web adds `egui-winit = { path = "engine/vendor/egui-winit" }` under `[patch.crates-io]` in its workspace root.
