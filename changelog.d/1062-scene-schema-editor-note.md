### `flint schema --format json-schema` writes `[post_process]` defaults as written; a value at a tuned bound is inside it (#1062)
**What changed.** The scene JSON Schema's `[post_process]` defaults are the decimals the effects declare (`bloom_intensity` `0.04`, not `0.03999999910593033`), so an editor's completion inserts `0.04`. A `[post_process]` value written exactly at a key's tuned bound (`0.7` where the range ends at 0.7) no longer warns that it is outside the range. The book's editor note now says how taplo resolves paths: a `.taplo.toml` rule's `path` and `include` are read against VS Code's workspace folder or `taplo lint`'s working directory, not the folder the file is in; a `#:schema` path is relative to the scene.
**What to do.** Regenerate `scene.schema.json` if you keep one. Open the project folder itself as the VS Code workspace, and run `taplo lint` from the project root.
