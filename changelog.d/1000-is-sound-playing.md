### `is_sound_playing(handle)`: a script can ask whether a sound it started still plays (#1000)
**What changed.** The handle from `play_sound` / `play_sound_at` can now be asked about. `is_sound_playing(handle)` is `true` from the frame after the sound starts until it plays out or the frame after `stop_sound`, on the desktop and through the web's worklet alike. It is `false` for a sound that never started (a name with no file, no sound device, a one-shot placed out of earshot, the web before Begin), for a handle nobody was given, and always in a headless capture (`flint render --scripts`), which has no sound. The answer is the mixer's as the frame began, so the frame a sound is started or stopped still reads as before.
**What to do.** Nothing. A script that kept its own timer to know when a voice line ended can ask instead: `if !is_sound_playing(line) { line = play_sound(next) }`.
