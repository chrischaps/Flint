### `flint render --frame-capture <dir>`: every pass's output image, beside the frame's description (#1085)
**What changed.** `flint render` can capture the frame it drew into a folder: `manifest.json` (the `--frame-dump` description, each pass now listing its `images`, written last) and `targets/NN-<target>.<ext>`, every target each pass wrote as that pass left it: the shadow cascades, the HDR scene before post, SSAO, each bloom step, the style mask, each style's output and its own targets, a user style's included. 8-bit targets are PNG, float targets OpenEXR half, depth OpenEXR f32. The last `surface` image is the `-o` output byte for byte. In Rust, `SceneRenderer::capture_next_frame` / `take_frame_capture` and `flint_render::frame_capture::write_capture` do the same for any host. The frame's textures are now made with `COPY_SRC`; a frame nobody captures draws the same bytes.
**What to do.** Nothing. To see what a pass drew, `flint render <scene> --frame-capture frame.flintframe` and open its `targets/`.
