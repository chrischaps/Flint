### A call into a script module the scene hasn't enabled is logged once a scene (#856)
**What changed.** Since #698 a call such as `tune_living`, `set_wooze` or `conducted_coherence` in a scene without the feature is a script error at its line. Since #693 a repeated error is logged at its 1st, 10th, 100th... time, so a shared HUD calling one of them in `on_update` still printed three lines in ten seconds and more as it ran. That error is now logged once for each call site in each scene: again only after a scene change or a reload of the script's file. It is still counted on every call, shown on the player's error card, listed in the end-of-run summary and `--report json`, and fails a run under `--strict-scripts`. Every other script error is logged as before.
**What to do.** Nothing. A script that should make no error at all in such scenes can ask first: `if module_enabled("living") { tune_living(knobs) }`.
