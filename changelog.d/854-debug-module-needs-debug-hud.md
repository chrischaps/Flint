### The `debug` script module (`compare_living`, `commit_living`...) needs the `debug-hud` feature (#854)
**What changed.** The Living Props panel's script calls (`commit_living`, `compare_living`, `flip_living`, `split_living`, `stop_comparing_living`) are enabled only in a player built with its `debug-hud` feature, as well as in a scene with living props. `debug-hud` is on by default and in `flint`'s own player, so `flint play`, `flint render --scripts` and `--frame-step` captures run them as before. A game binary built without `debug-hud` gets a script error at the call: `compare_living: the debug module is not enabled here; it is enabled when the player is built with its debug-hud feature (on by default) and the scene has living props, ...`. The `living` and `wooze` modules are unchanged.
**What to do.** Nothing for a game that keeps the default features. A game that ships without `debug-hud` and calls these from a script should call them only in its dev build, or ask `module_enabled("debug")` first.
