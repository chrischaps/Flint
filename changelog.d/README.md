# Changelog entries waiting to be assembled

Each file here is one pull request's changelog entry, named
`<issue>-<slug>.md` (`bash scripts/changelog.sh new <issue> <slug>` writes
one). After the merge, the `Changelog` workflow moves the entries into
`changelog/YYYY-MM.md` under the merge's date and deletes the files. How to
write one: [CHANGELOG.md](../CHANGELOG.md), "Adding an entry".
