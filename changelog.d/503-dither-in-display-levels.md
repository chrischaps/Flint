### `[post_process] dither_style`: dither that hides banding in the dark (#503)
**What changed.** The composite's dither was added in linear light, before the target's sRGB encode, so near black it came out about 13 times as many display levels as in the midtones: any `dither_intensity` small enough to vanish in the light laid an 8x8 crosshatch over a dark scene. A new key, `dither_style`, says where it is added: `0` (the default) is linear light, exactly as before; `1` is the same Bayer matrix in display levels; `2` is triangular noise in display levels, with no tile. In styles 1 and 2, `dither_intensity` counts display levels over 255 at every brightness, so `0.004` is one 8-bit step. Scenes that set no style draw byte for byte as they did.
**What to do.** Nothing, unless a dark scene bands: set `dither_enabled = true`, `dither_style = 2`, `dither_intensity = 0.004`. `examples/dark_stage.scene.toml` shows it.
