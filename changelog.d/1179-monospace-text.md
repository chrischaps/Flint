### `font: "monospace"` draws fixed-pitch text, and a `fonts.toml` alias may name a face by path (#1179)
**What changed.** `draw_text`, `measure_text`, `draw_world_text` and a UI document's `font` take `"monospace"` and `"proportional"`, egui's two built-in families: one `draw_text` call draws a line of code or a column of numbers in a fixed pitch with no font file of the game's, and `measure_text` with the same `font` is the width it draws. Before, both names fell back to the proportional face with a warning. A project file or alias of either name still comes first, and with `[egui] monospace` set the name draws the game's own face. A `fonts/fonts.toml` alias's `file` may now be a relative path from the manifest's folder (`file = "ofl/VT323/VT323-Regular.ttf"`, or `../vendor/Mono.ttf`), so a face kept in a subfolder for a glyph set is a HUD font without a second copy; it registers under the alias only. A manifest is read even when `fonts/` holds no font file of its own.
**What to do.** Nothing. A script that drew fixed cells one character at a time can draw the line with `font: "monospace"`.
