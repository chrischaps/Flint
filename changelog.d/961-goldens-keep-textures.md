### `flint goldens` uploads each texture once a run (#961)
**What changed.** In one process, `flint goldens` now keeps the models' and image files' textures on the GPU device for the next case, as it keeps pipelines since #911, keyed by their pixels, so a changed file still uploads fresh. On WARP a case on a scene with several 2048-texel textures took 3 to 13 s just to upload them; the stylize suite's run on CI's WARP job drops by about 5 minutes on most runners. The run's last line now ends `textures: N uploaded, M reused`, and `--fresh-pipelines` also uploads every case's textures anew. While the cache is on, `TextureCache::update_rgba` refuses a kept texture (a host that writes a texture by name should leave `pipeline_cache` off, as the player and the editors do).
**What to do.** Nothing. A script that parses the summary line should allow the new `textures:` part.
