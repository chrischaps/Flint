### User style images: folders listed while the game runs, and `mips = true` (#558)
**What changed.** An image option with no `choices` (it offers the images in its default's folder) now lists that folder again while the player or the scene viewer runs: a PNG added there or deleted changes its choices with no save of the `.shader.toml`, and the game's settings for the style are kept. `StyleRegistry::reload_changed_for`'s `Reload` has a new field, `rechosen`, for these styles; `changed()` counts it. `[images.<name>]` and an image option take `mips = true`, which uploads a mip chain: `flint_image_<name>` and `flint_image_tiled_<name>` then read the level the screen asks for, and `flint_image_lod_<name>`, `flint_image_level_<name>` and `flint_image_tiled_level_<name>` are new. An image without `mips` draws exactly as before. `examples/styles/darkroom`'s paper has it.
**What to do.** Nothing. A host that builds `Reload` by hand adds `rechosen`. Give a paper or brush sheet that is drawn smaller than its texels `mips = true`; leave it off for a LUT.
