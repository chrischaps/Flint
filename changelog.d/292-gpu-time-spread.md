### `flint render --gpu-time` prints min/p50/p90/max per pass; `--gpu-time-json` (#292)
**What changed.** `--gpu-time N` used to print each pass's exponentially smoothed time, which hid how much the frames varied. It now keeps every frame's raw times, drops the first tenth (at most 30) as warm-up, and prints a table of `min p50 p90 max` per pass plus the frame total. Its first line names the adapter and backend (`on NVIDIA ... (Vulkan):`), so a `WGPU_BACKEND` run shows which one it measured. The new `--gpu-time-json <file>` writes the same with each pass's mean and raw `samples_ms`. In flint-render, `GpuTimer::record(on)`, `recorded()`, `flush(device)` and `gpu_timer::spread(frames, drop)` give a host the same numbers; `HeadlessContext` gained `adapter_info`. The player's smoothed overlay is unchanged.
**What to do.** A script that parsed the old one-number-per-pass lines should read `--gpu-time-json` instead, or take the `p50` column.
