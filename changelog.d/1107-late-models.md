### A chunk's models, and a script's `spawn_entity` models, draw (#1107)
**What changed.** The player loaded model files only when a scene was entered, so an entity a `load_chunk` brought in, or a script made with `spawn_entity` and `set_field(id, "model", "asset", ..)`, drew nothing unless the scene already used that model. Now the player loads them: a chunk's on the frame `load_chunk` is carried out (its `model load` frame note inside the `chunk load`), a script's at the end of the frame it was spawned on, through the scene's search (catalog, procgen spec, file), textures and skeletons included. Each file is read once; later spawns of it draw the mesh already loaded. A `model` given to an entity spawned in an earlier frame is still not loaded, and `flint render --scripts` draws only the scene's own models.
**What to do.** Nothing. A game that worked around it by naming every streamed model in its scene can drop those placeholder entities.
