### Scripts read the wooze field and its beat: `wooze_at`, `wooze_beat`, `module_enabled` (#505)
**What changed.** The `wooze` script module could only change the field; now it reads it too. `wooze_at(x, y, z)` returns `#{ amplitude, step, glide, jitter, zones }` at a place, zones and scripts' changes included. `wooze_beat(x, y, z)` returns the hold-and-glide clock there, the one shallow wooze keeps: `#{ time, delta, beat, index, weight, amplitude, step }`, where `time` and `delta` hold still on the beat and stand in for `total_time()` and `delta_time()`. Both return `#{}` in a scene with no `[wooze]` table. The new core function `module_enabled(name)` says whether an optional feature's module (`wooze`, `living`, `debug`, `conducted`) can be called in the scene. The showcase's `creature_idle.rhai` bobs on the beat where a scene has `[wooze]`, and as before elsewhere.
**What to do.** Nothing. To make scripted motion hold with living props, read `wooze_beat` behind `module_enabled("wooze")` (the book's Wooze API).
