### The egui 0.30 to 0.36 port covers `Shadow`, `scope_builder`, `Tooltip`, the `Visuals` corner radii and egui_plot 0.37 (#983)
**What changed.** [Upgrading the Engine](https://docs.chaps.dev/guides/upgrading-the-engine.html#egui-030-to-036) had the renames Flint's own code needed. It now has the ones a game's client hit too, each 0.36 form compiled against egui 0.36.2: `Shadow`'s `[i8; 2]` offset and `u8` blur and spread, `allocate_new_ui` to `scope_builder`, `show_tooltip_at_pointer` to `Tooltip::always_open`, `Visuals`' `window_corner_radius`, `menu_corner_radius` and `corner_radius`, `painter.rect`'s `StrokeKind`, `ScrollArea::scroll_source`, `TextEdit::frame(Frame)`, `Sense`'s methods, and egui_plot 0.37's named items. It names the version of each companion crate (egui_plot 0.37.0 goes with egui 0.36), says a `ScrollArea` now drags only on a touch screen, and points to egui's CHANGELOG for the rest. A correction: `StrokeKind::Outside`, not `Middle`, is where egui 0.30 drew a rect's stroke.
**What to do.** A game porting its own egui code: read the table again. One that already passed `StrokeKind::Middle` for 0.30's look draws its rect strokes half a stroke inside it; pass `Outside` to get it back.
