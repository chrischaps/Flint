### `flint validate` checks style palettes, fonts, papers and strokes (#1063)
**What changed.** `ascii_style.palette` and `font`, `pencil_style.paper_image` and `stroke_image`, `watercolor_style.paper_image` and `ui_text.font` are `asset` fields now, so a name that is neither a file nor a built-in (`palette = "ambr"`) is a `missing-asset` error whose hint suggests the nearest built-in. Built-in names (`amber`, `cga`, `builtin`) and `"none"` for a paper or stroke image pass with no file. A schema's `asset` field can list such names itself: `builtins = ["none"]`. `palette = "none"` is reported too: the renderer never took it, and drew `cga` with a warning.
**What to do.** Run `flint validate` (or `flint check`) and fix any name it reports; a palette you meant to leave unused can be left out.
