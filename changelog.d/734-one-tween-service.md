### `tween(entity, "component.field", target, seconds[, easing])` eases any numeric field; `fade_anim_layer` takes an easing (#734)
**What changed.** Scripts can ease any number or list of numbers a component holds (a light's `intensity` or `color`, a material's `emissive`, a transform's `position`) on game time with one call, which fires `tween_done` with `#{ entity, path }` when it arrives; a write by anything else (a `set_field`, physics) takes over. `fade_anim_layer(id, index, weight, seconds, easing)` eases a layer's weight, written as the layer's new `fade_easing` key (linear when absent, as before). Every timed change now names one set of easings, `flint_core::tween::Easing` (`flint_player::Easing` is it), and rides one `Ramp` / `Tween`: style tweens, layer fades, crossfades, the wooze field (byte-identical) and Living Props' knobs. A style tween now lands exactly on its target.
**What to do.** Nothing. A script that lerps a field in `on_update` can call `tween` instead. A game whose own Rhai defines a `tween` function with four or five parameters shadows the engine's; rename it.
