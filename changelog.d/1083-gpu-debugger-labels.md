### Frames are named for RenderDoc and PIX: `FLINT_GPU_LABELS`, `?gpu_labels=` (#1083)
**What changed.** A captured frame now reads in RenderDoc, PIX or Nsight as nested debug groups. They use the names the F2 overlay times (`Shadows`, `Scene`, each effect and style, `Composite`, `UI`). Inside them are a pass per shadow map (`Shadow cascade 0`, `Spot shadow`) and a group per layer of the draws (`Opaque static`, `Particles`, ...). Natively, groups are always on. Under a capture tool, or with `FLINT_GPU_LABELS=1`, each draw is also marked with its entity's name and kind (`barrel · Static`). `groups` and `0` give less. The web player adds none unless the page has `?gpu_labels=1`. No pixel changes. A host that times its own pass can open it with `flint_render::gpu_labels::begin` / `end` for a group of the same name.
**What to do.** Nothing. To capture a frame, see the book's Profiling guide, "Capturing a frame in RenderDoc".
