### `FLINT_STYLE_SHADER_DIR` hot-reloads the built-in styles' WGSL (#418)
**What changed.** The built-in styles' shaders are still compiled in, and a shipping build reads nothing else. With `FLINT_STYLE_SHADER_DIR` set to the engine's `crates/flint-render/src/stylize` (from a game: `engine/crates/flint-render/src/stylize`), natively, the viewer, the player and `flint render` read each built-in style's `.wgsl` files from that folder instead, shared ones such as `ascii_common.wgsl` and `../palette.wgsl` included. They build again each style whose file changed, about half a second after a save (470-672 ms over nine edits in `flint edit examples/watercolor.scene.toml`). A file naga rejects shows a `file:line:col` error in the style error card, and the last good shader keeps drawing. So does a shader wgpu refuses (a renamed entry point). The variable does nothing on the web.
**What to do.** Nothing. To tune a built-in look by eye, set the variable and edit the shader while the scene is open. Unset it when you're done: a warning at start-up says while it's on.
