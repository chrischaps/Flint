### `flint edit` saves what differs from the file, prefab entities included, and logs each field to `.flint/viewer-edits.jsonl` (#679)
**What changed.** The scene viewer's Ctrl+S writes every field that differs from the file, so an undo after a save marks the scene dirty and the next save writes the value it put back. An edit to an entity a prefab instance makes is no longer dropped: it goes into `[prefabs.<instance>.overrides.<entity>.<component>]`. An edit that can't be written anywhere is named in red in the status bar and keeps the title's `*`; "Saved!" means everything was written. Each save appends one JSON line per field (`entity`, `component`, `field`, `old`, `new`, `table`, `saved_at`, `scene`) to `.flint/viewer-edits.jsonl` under the project root, so an agent can read what a person changed.
**What to do.** Add `.flint/viewer-edits.jsonl` to your game's `.gitignore` (`flint init` does it for new projects). An agent working with a person in the viewer can read the file's tail after they save.
