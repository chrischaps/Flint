### `flint edit --render` works for every file, and a flag an editor doesn't take is an error (#712)
**What changed.** The six editors (scene viewer and track editor, model, procgen, texture pipeline, terrain, particles) run in one host, `flint_viewer::host`. `--render out.png` now writes a still for procgen meshes, procgen textures, texture pipelines (their maps side by side), terrain, scenes and the track editor too, not only models and effects. `--width`, `--height`, `--no-grid`, `--distance`, `--yaw`, `--pitch`, `--target` and `--fov` mean the same in every editor with a 3D view (terrain and procgen meshes gained the camera flags). A flag the file's editor doesn't take, which used to be ignored or warned about, now stops with an error naming the editors it applies to; `--anim-time` and a model's or effect's `--style` need `--render`. In the previewers egui panels now blend in display space as the scene viewer's do (#428), so translucent panels read slightly darker. Model and effect stills are byte-identical to before.
**What to do.** Drop any flag a script passes to an editor that never took it. Code calling `flint_viewer::app::run` or `run_editor` needs no change; `app::viewer` / `app::track_editor` hand the viewer to `flint_viewer::host::run` or `render_still` instead.
