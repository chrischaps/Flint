### flint-music lives in `engine/packages/music/crates/flint-music` (#1555)
**What changed.** The music package's crate moved into its package folder, with the player's music subsystem (`flint_music::player`, behind its `player` feature) and the `flint music validate|play|render` commands (`flint_music::cli`, behind `cli`). A manifest's `[rust]` table takes `player = "<crate>"` beside #1554's `cli`, and flint-player's build lists that crate's `player::PACKAGE` from it. `flint music` is now listed after the engine's own commands in `flint --help`; every command, flag and output is as before. A flint built without `music` has no `music` command at all and names the package for one, exit 2, as before. `flint_package::SceneCtx` has a new `registry` field, and `MissingPackage` is `flint_package::cli`'s (flint-cli re-exports it).
**What to do.** A game whose own `Cargo.toml` names `engine/crates/flint-music` by path changes it to `engine/packages/music/crates/flint-music`. A game that builds a `SceneCtx` by hand adds `registry: flint_player::packages::registry()`. Nothing else.
