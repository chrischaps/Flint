### `flint edit`: Commit to scene no longer resets the rest of F4 (#516)
**What changed.** F4 → Styles → **Commit to scene** writes one style into the scene file, and the viewer's file watcher then reloads the scene. That reload used to take the whole `[post_process]` from the file, so a bloom, fog or SSAO value (or another style's settings) tuned in F4 and never written anywhere snapped back to the authored value without a word. The reload a commit causes now leaves the post-process on screen as it was; those other values are still not in the file, and the button's hover text says so. Any other reload, such as an edit of the file in a text editor, takes the file's `[post_process]` as before.
**What to do.** Nothing. To keep a tuned bloom or fog, write it into the scene's `[post_process]` yourself; Copy TOML and Commit to scene carry only the one style.
