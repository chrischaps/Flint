### `flint frame replay --pass`: step a shadow cascade or a style pass a draw at a time (#1204)
**What changed.** A replay could stop only the scene pass after N draws. `--draws N` now steps whichever pass `--pass` names: `Shadow cascade 0` to `2`, `Spot shadow`, `Style mask` or `Style albedo` (`Scene` is still the default). Every other pass draws whole, so a cascade's casters can be stepped while the scene reads the other layers as captured. The report gains `pass` (the stepped pass's own images against the captured ones) and `pass_draws`, and `controls` now carries `pass` and `draws` where it had `scene_draws`. In `flint frame open` the draws slider and `[`/`]` follow the selected pass when it can be stepped. The frame description now lists the style mask's and albedo's draws. In Rust, `flint_render::DrawControls` swaps `scene_draws: Option<usize>` for `limit: Option<DrawLimit { pass: SteppedPass, draws }>`.
**What to do.** Nothing, unless a script reads `controls.scene_draws` from `frame replay --json` (read `controls.draws`), or Rust code builds a `DrawControls` (write `limit: Some(DrawLimit { pass: SteppedPass::Scene, draws: n })`).
