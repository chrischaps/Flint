### A player built without a package names its components once, with `flint build` (#1601)
**Package.** engine
**What changed.** In a player built or launched without a package (`living`, say), a scene that uses its components or scene tables used to hear three things at its entry: the load summary's `error[unknown-component] ... living_prop` and `warning[unknown-table] [wooze]`, with the hint for a name nobody has heard of, and then the player's own `[living] this player is built without the `living` package: the scene's living_prop, [wooze] stand still`. Now the last line is all it hears, and it ends with what to do: `; run `flint build` in the project for a player with it` (or, where `[packages]` leaves the package out, the line to add first). `flint playtest` counts one load warning there, where it counted four lines (the summary's count line, the two diagnostics and the line). A component no package provides is still `unknown-component`, and a package `[packages]` leaves out is still `unlisted-package`.
**What to do.** Nothing. A test that matched the old `[living] ...` line exactly will see it end with the hint now.
