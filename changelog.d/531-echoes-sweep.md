### `flint render --sweep living.echoes.spread=...`, `.alpha` and `.count` (#531)
**What changed.** `--sweep` takes the scene's `[living] echoes` fields as keys: `--sweep living.echoes.spread=0,0.9,1.8 --time 1.5` draws one labelled sheet with a column a spread, each column what a scene with that `[living] echoes` table draws, pixel for pixel (the scene's other `[living]` values and any species' own `echoes` apply as in the file). Values are checked as a spec's echoes are (`count` up to 16, `spread` 0 to 1.82, `alpha` 0 to 1) before anything loads, and a scene with no living props is refused. Two keys make a grid as with any sweep (`--sweep living.echoes.spread=... --sweep living.echoes.alpha=...`). Nothing a scene, spec or script says changes.
**What to do.** Nothing. A script that writes one scene copy per echoes value and tiles the renders can use the one command instead.
