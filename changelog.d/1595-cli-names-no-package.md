### A package's spec files and sweep keys come from its manifest: `[provides] specs`, and `render --sweep wooze.*` lines (#1595)
**What changed.** A package manifest has an eighth `[provides]` list, `specs`: the spec files the package makes assets from, as a pattern of their names (procgen's `"*.procgen.toml"`). `flint package used` credits a scene, chunk or prefab that names such a file (by path, or by the name the spec states) to the package that lists the pattern, as it did procgen's before; its text and JSON are unchanged. A `[provides] flags` line's value may end in `.*` to name every value past the prefix: living lists `"render --sweep wooze.*"` and `"render --sweep living.*"`, and a `flint` built without living refuses `flint render x --sweep wooze.glide=0,0.5` naming the package from those lines (exit 2, `package` in the `--json` error), as before. The `[living] echoes` a `--sweep living.echoes.*` cell draws are written by the living package (`StagePart::lay_tables`), byte for byte as before.
**What to do.** Nothing. A game's own package that makes assets from spec files of its own can list their pattern under `specs`.
