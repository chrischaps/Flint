### `global::NAME` reads a script's top-level `const` from callbacks again (#1012)
**What changed.** Since #692 (a script's top level runs once), a callback, or a function it called, that read a top-level constant as `global::NAME` failed with `Variable not found: global::NAME`, every call. Rhai records a constant for `global::` only as its `const` statement runs, and callbacks no longer ran the top level. Now each constant a script reads as `global::` is handed to every callback with the value its one top-level run made: the initializer (`const DOOR = get_entity("door");`) still runs once, and a hot reload's new constants are included. A bare `NAME` worked throughout and is unchanged. A script with no `global::` read costs nothing more per callback.
**What to do.** Nothing. A game whose engine is at #692 or later and whose scripts read `global::` (Float: time of day, birds, music, water, weather) pulls this to stop the errors.
