### `flint-cli` has package features: `living`, `music`, `rhythm`, `procgen`, `ai` (#1333)
**What changed.** Each package of ADR 0136 is a Cargo feature of `flint-cli`, on by default and forwarding to `flint-player`'s; `packages` turns on all five. A build without one links none of its crates (music, rhythm and pad capture, living props, the AI generators and cost ledger). Its commands stay in `flint --help` and still parse, but running one, or a flag that needs it (`gen --ai-create`, `render --ai-refine`, `gen --strip`, `music validate --chart`), exits 2 naming the package; under `--json` the error document carries `package`. `flint package list --built` lists the packages a binary was compiled with. The default build is unchanged: every help page but `package list`'s is byte for byte the same.
**What to do.** Nothing, for a default build. A headless build that used `--no-default-features` and still wants every command adds `--features packages` (`cargo build -p flint-cli --no-default-features --features packages`).
