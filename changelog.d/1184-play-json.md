### `flint play --json` is flint's global flag again (#1184)
**What changed.** `flint play <scene> --list-keys --json` prints the debug-key table as JSON, and so does `flint --json play <scene> --list-keys`. Before this, both were refused as a window command, so the line the book gave never worked. A plain `flint play --json` is now refused with flint's window-command error (exit 1, an `error` document). It used to fail with a clap error asking for `--list-keys` (exit 2). `flint-player --list-keys --json` is unchanged. A game binary that set `PlayerArgs::json` from clap now sets it itself: the field is still there, but it is no longer a flag.
**What to do.** Nothing, unless a game's own binary flattens `PlayerArgs`: then give it a `--json` of its own and copy that into `args.json`, the way `PlayerCli` does.
