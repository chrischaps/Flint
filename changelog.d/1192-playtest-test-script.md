### `flint playtest --test-script <file>`: a playtest's own Rhai checks (#1192)
**What changed.** A playtest can run Rhai checks that live beside its input script instead of in the game's scripts. Each `--test-script` (repeatable) is attached to an entity the run spawns in every scene it enters (`playtest`, then `playtest_2` ...), loaded beside the scene's scripts, with the whole script API and the `test_*` functions. Assertions and verdicts name its file and entity, `--strict` holds it to the script API before the run, and a file that isn't there fails the run at its start. A scene with an entity named `playtest` of its own gets a script error when a test script needs that name.
**What to do.** Nothing. A check that went into a game script only to test it can move to a `--test-script` file.
