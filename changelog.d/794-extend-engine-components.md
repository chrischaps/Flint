### A game adds a field to an engine component with `extend = true` (#794)
**What changed.** A schema file's `[component.<name>]` (or `[table.<name>]`) may say `extend = true`: its fields are then added to the component an earlier schema directory declared, instead of replacing it whole. A field named again is redefined; the earlier layer's description and fields stay. An extension of a name nothing earlier declares fails the load, naming the file and the nearest name. Without `extend`, a later layer still replaces a component whole, so existing files mean what they did. `flint schema <name>` prints `Declared in:` and `Extended by:` and tags each field with its file's number; `--format json` adds `declared_in`, `extended_by` and each field's `file`. The unknown-field hint now names the key. For Rust: `SchemaRegistry::component_origin` / `table_origin` return a `SchemaOrigin`.
**What to do.** A game that copied a whole engine component file to add a field can cut it to `extend = true` and its own fields, and stop tracking the engine's copy.
