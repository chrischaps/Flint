### The `procgen` load stage, frame note and frame stage read `made assets` (#1632)
**Package.** engine
**What changed.** The kernel named three labels after the procgen package; they now name what the kernel does there, the asset makers' point (`flint_package::assets`). `--load-report`'s table row and its JSON `stage` read `made assets` (was `procgen`), and a slowest item reads `made asset <name>` (was `procgen asset <name>`). The hitch log's and the frame history's note reads `made assets` (was `procgen`). The frame stage a subsystem or extension hears is `Stage::MadeAssets` (was `Stage::Procgen`), at the same place in the frame, and its profiler scope's detail reads `made_assets`. In Rust, `flint_core::load_report::Stage::Procgen` and `flint_core::frame_notes::NoteKind::Procgen` are `MadeAssets` too. The load summary's `procgen assets` count is the procgen package's own and is unchanged.
**What to do.** A game binary that matched `Stage::Procgen` matches `Stage::MadeAssets`. A tool that reads `--load-report --report json` or the hitch log for `procgen` reads `made assets`.
