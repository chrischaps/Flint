### `procgen = false` under `[packages]` makes no spec asset in a stock player or `flint render` (#1578)
**Package.** engine
**What changed.** A player built with procgen (the stock `flint-player`, `flint play`) used to make every `*.procgen.toml` asset a scene named even when the project's `[packages]` set `procgen = false`. Now it makes none: a model or texture a spec names loads from its file, or draws nothing, as in a build without procgen. The scene's entry says one line, `[procgen] [packages] in flint.toml leaves out `procgen`: the scene's N assets named by a spec (...) load from files, where there are any`, followed by the line to take out. `flint render` now reads the list too: with `procgen = false` (which leaves `living` out with it) a grove's props stand still and are reported in `still_props`, and living's left-out line is said, where the render used to grow them. A project that lists procgen, or has no `[packages]` table, renders and plays byte for byte as before.
**What to do.** If a game sets `procgen = false` and still wants its spec assets, remove that line, or bake the specs to files with `flint gen`.
