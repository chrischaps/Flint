### A `music_session` with a `chart` uses the `rhythm` package: `flint package used` names it, `flint check` asks for it (#1581)
**Package.** rhythm
**What changed.** The rhythm manifest lists the session's rhythm fields (`chart`, `lean_mode`, `input_map`, the four `*_config` paths, `bars`, `quit_on_finish`, `tuning_config`, `bindings`) under a new `[provides] fields` key, as `music_session.chart` and so on. `flint package used` reads each field a scene writes, so a charted session names `rhythm` as well as `music`, with the field as its use, and `--write` lists both. In a game whose `[packages]` lists `music` and not `rhythm`, `flint check` and `flint validate` report such a field as an `unlisted-package` error (one per file), and the player's load summary says the same, with the hint to add `rhythm = "*"`. A session with no rhythm field still needs `music` alone. `flint package list` shows the new `fields` row, and its JSON has a `fields` list for every package.
**What to do.** If `flint check` now fails on a charted scene, add `rhythm = "*"` under `[packages]` (or run `flint package used --write`). Before, the chart was never judged in that game.
