### Rhai `get_look()` and `list_looks()`: a script asks which look is on (#497)
**What changed.** `get_look()` returns the look the scene draws with now: the one its `[post_process] look` names, `--look`, or the last that a script's `set_look`, F4's Look picker or a transition chose. It returns `""` for none, and a fade's target from its first frame. `list_looks()` returns every look the scene can see, sorted by name: the project's `styles/*.look.toml` files and the built-ins, as F4 lists them. `set_look` is still a queued command, so a read in the same call after it returns the old look, and from the next read after the player applies it (that frame's `on_draw_ui`) it returns the new one. In a `flint render --scripts` capture, a `set_look` whose look can't be found is now refused at the call with the player's `set_look:` warning. It no longer replaces an earlier request from the same frame.
**What to do.** A menu or HUD that kept its own copy of the current look can call `get_look()` instead, and that copy no longer goes stale when F4 or a scene change picks one. Nothing else.
