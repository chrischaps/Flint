### A new kernel crate, `flint-package`: the Package API (#1550)
**What changed.** The player's subsystem trait, `Stage` and the contexts each hook is lent moved out of `flint-player` into a crate of their own, `flint-package` (ADR 0137), so a package's crate can build against them without depending on the whole player. What one package lends another (the procgen resolver, the living props, the F3/F4 panels) now travels in the run's typed `Resources` rather than as feature-gated context fields. `flint_player::Stage` is `flint_package::Stage`, re-exported, so a `PlayerExtension::update(stage, ..)` compiles unchanged, and `PlayerExtension` itself is unchanged. Frames, captures and the exit report are the same as before.
**What to do.** Nothing. A game's engine subtree gains `crates/flint-package`, which the workspace already lists.
