### Render modes 1-6 are styles and a tear: `matrix`, `blood`, `drunk`, `tron`, `underwater`, `[post_process] tear`, the ocean's `tint` (#746)
**What changed.** The composite and ocean shaders no longer carry render modes. Each look is a display style with named params (`flint render --list-styles`). The tear is three `[post_process]` keys: `tear`, `tear_scale` (default 3) and `tear_iris`. Set them with `--tear` or Rhai `set_tear` / `set_tear_shape`, which hold until set again. A style shows only in the tear's holes when its table says `blend_source = "tear"`, the key props already use. The sea's blood and underside are the `ocean` component's `tint*` fields. `PostProcessConfig` lost `render_mode`, `mode_mix` and `mode_params`, and `flint_player::apply_look` takes a `RenderModeShim`. `--render-mode`, `set_render_mode` and `set_render_mode_params` are deprecated shims for one release: they still draw each mode, transient as before.
**What to do.** Move to the styles: mode 1 is `set_post_style("matrix", true)`, `set_post_style_param("matrix", "blend_source", "tear")` and `set_tear(mix)`. Drunk and underwater take `blend` (underwater's x..w are `depth`, `churn`, `daylight`, `glow`). For blood, also set the ocean's `tint`. Set the tear back to 0 when it ends.
