### `flint edit <scene>` honours `--width`, `--height` and `--no-grid` (#423)
**What changed.** The scene viewer, and the track editor `--spline` opens, ignored these three flags: every scene opened a 1600 x 900 window with the editor grid drawn. They now size the window and turn the grid off, as they already did in the model, procgen, texture, terrain and particle editors. Without them the viewer still opens at 1600 x 900 with the grid. A game binary or tool that calls `flint_viewer::app::run` or `run_editor` itself passes one more argument, a `flint_viewer::app::ViewerWindow` (`ViewerWindow::default()` keeps the old window).
**What to do.** Nothing, unless you call `flint_viewer::app::run` / `run_editor` from Rust: add `Default::default()` as the last argument. To capture a styled scene that reads depth without the grid in it, pass `--no-grid`.
