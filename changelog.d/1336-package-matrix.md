### An examples index entry takes `packages`, and CI builds each package alone (#1336)
**What changed.** An `[[example]]` in an `index.toml` may say `packages = ["living"]`: the packages its scene needs beyond the kernel. `flint examples --check` on a flint built without one of them passes over that example by name (`SKIP <scene>: needs the living package, which this flint was built without`; JSON `skipped`) instead of failing it, and a name no package manifest has is a failure. `flint examples --json` lists each entry's `packages`. The engine's CI has a `package matrix` job (`scripts/package-check.sh --build`): flint-player and flint-cli are checked with no package, the standard set, each package alone and all of them, and a tree that links a left-out package's crate fails.
**What to do.** Nothing. An examples repository that wants `--check` to pass on a slim flint lists each scene's packages in its index.
