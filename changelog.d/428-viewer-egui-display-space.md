### `flint edit`'s panels blend as the player's do; `RenderContext::hud_view` (#428)
**What changed.** The scene viewer (`flint edit <scene>`) drew its egui into the swapchain's sRGB view, so egui-wgpu wrote linear colour and the GPU blended translucent panels in linear light. A dark translucent ground came out grey: the user-style error card read lighter there than in `flint play`. The viewer now draws egui into the plain (non-sRGB) view, as the player always has, so every translucent panel in the viewer (the error card, F4, the view gizmo's disc, the spline editor's polygon) reads darker and the same as in the player. Opaque panels and the 3D scene are unchanged. `RenderContext::hud_view(&texture)` is new: the view an egui pass draws into, in `hud_format`, the format to build the `egui_wgpu::Renderer` for.
**What to do.** Nothing for a game. A game binary with its own egui pass on a `RenderContext` should draw into `hud_view` with a renderer built for `hud_format`, or its translucent colours read too light.
