### `.font.toml`, `.atlas.toml` and `fonts/fonts.toml` warn about keys they ignore (#282)
**What changed.** These three formats used to skip any key they didn't know, so a misspelled `spacng` or a key written after the wrong `[table]` header changed nothing and said nothing. Each key they ignore is now a warning when the file loads. The warning names the file, the key and its table, and suggests the likeliest fix: "did you mean `spacing`?", "it is a key of [egui]", or, for a top-level key written below a header, "move it above the header". A single `[font]` in `fonts.toml`, where the format wants `[[font]]` entries, is reported, and so is an atlas region that isn't `[x, y, w, h]` in whole pixels (still skipped). Files load as before.
**What to do.** Nothing. If your game logs new warnings, fix the key each one names. A loader of your own can describe its format as a `flint_core::toml_util::Shape` and log what `check_keys` returns.
