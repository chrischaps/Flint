### `flint render --strip`: a `--time` span or list as one PNG contact sheet (#574)
**What changed.** `flint render <scene> --time 0..8 --strip --every 1 --columns 3 -o x.png` writes the span as one labelled PNG: a tile every `--every` seconds (default 1), the span's end included when a step lands on it, each tile labelled `t = 2 s`. A list (`--time 2,5,9.5 --strip`) makes a tile a moment. Tiles are 640 x 360 unless `--width`/`--height` say otherwise, `--columns` (alias `--cols`) sets how many go across, and `--label off` draws the tiles alone, 4 pixels apart, for a script to cut back out. Each tile is the pixels of `--time <t>` rendered alone at that size: the clocks run on the GIF's `--frame-step`, and each tile is drawn as a first frame (a style's history starts fresh). Nothing else a render writes changed.
**What to do.** Nothing. A gate script that renders each second as its own still and tiles them can call `--strip` instead.
