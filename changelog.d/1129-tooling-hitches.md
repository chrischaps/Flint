### Screenshots and opening F2 are `tooling` hitches, not the game's (#1129)
**What changed.** Each `--screenshot` / `--screenshot-every` frame and the first frame F2 shows a view on now leave a frame note (`screenshot <file>`, `stats overlay opened`). A hitch they account for is classed `tooling`: the hitch log writes `"class":"tooling"` with the tool as its `cause`, where a screenshot used to read `elsewhere, present 92.5 ms`. The exit report counts these on a new line, `[perf] tooling hitches (screenshots, the F2 overlay; never gated): ...`, and leaves them out of `[perf] hitches:`, the perf line, the F2 counters, `--capture-on-hitch` and every `--max-hitches` gate. Debug builds now build egui's text stack (epaint, harfrust, skrifa, vello_cpu) optimized, so the first F2 press costs about 12 ms instead of about 110 ms. A game's own text at a new size gets faster the same way, and a cold debug build takes a little longer.
**What to do.** Nothing, unless a tool reads the hitch log's `class`. It can now say `tooling` as well as `player` and `elsewhere`.
