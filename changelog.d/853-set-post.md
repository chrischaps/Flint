### Scripts: `set_post(key, value)` sets any `[post_process]` key; the old post setters are deprecated (#853)
**What changed.** One function now sets any key of the scene's `[post_process]` table, by the scene's own name for it: `set_post("vignette_intensity", 0.4)`, `set_post("fog_color", [r, g, b])`, `set_post("fxaa", true)`, `set_post("ssao_samples", 16)`. A key that doesn't exist, or a value of the wrong kind, is a script error that lists the keys, and `flint script check` catches a misspelled literal key. The 13 single-purpose setters still work for this release and warn in `flint script check`:
`set_vignette(v)` → `set_post("vignette_intensity", v)` (it also set `vignette_enabled` to `v > 0.001`) · `set_bloom_intensity` → `bloom_intensity` · `set_exposure` → `exposure` · `set_chromatic_aberration` → `chromatic_aberration` · `set_radial_blur` → `radial_blur` · `set_ssao_intensity` → `ssao_intensity` · `set_fog_density` → `fog_density` · `set_fog_color(r, g, b)` → `set_post("fog_color", [r, g, b])` · `set_desaturation` → `desaturate` · `set_dof` → `dof_strength` · `set_dof_focus(d, r)` → `dof_focus_distance`, `dof_focus_range` · `set_tear` → `tear` · `set_tear_shape(s, iris)` → `tear_scale`, `tear_iris`. A Rust host: `ScriptCommand::SetFogColor` and `ScriptHost::set_fog_color` are gone (the colour rides in `SetPostProcess`), and `PostProcessOverrides` is a key map (`get`, `f32`, `iter`).
**What to do.** Replace each old call with its `set_post` form; `flint script check` lists them. If you call `set_vignette` in a scene whose `vignette_enabled` is false, add `set_post("vignette_enabled", true)`.
