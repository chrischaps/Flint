### A debug key with nothing to act on says so on screen (#367)
**What changed.** Pressing F3 in a scene with no debug panels, F4 with no renderer, `` ` ``, `\` or F9 with no music session, or F8 with no living prop at the view centre used to log at `info`, which the player's log filter never prints, so the key seemed to do nothing. Now a short note shows at the top centre of the window for about two seconds (the key as a keycap, then what it found), fading out, and the console gets the same line as `[debug] F3: no debug panels in this scene`. F9's old `[music] no music session running — nothing to fail` line is now `[debug] F9: ...`. A capture under `--frame-step` shows the note on the same frames every run, since it runs on egui's clock. Builds without the `debug-hud` feature are unchanged.
**What to do.** Nothing. A test or tool that read F9's `[music]` line reads the `[debug] F9:` one instead.
