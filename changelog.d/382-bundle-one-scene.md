### `flint bundle <scene>` packs one scene with what it reaches; `flint check` reads glTF models' outside files (#382)
**What changed.** `flint bundle levels/x.scene.toml` (a scene file, not a folder) writes `levels/dist/x.flintpack` holding that scene and only the models, textures, sounds, scripts, prefabs and scenes it reaches, followed through scripts and prefabs to the end of the chain. It also holds the small kinds its search sees (animations, styles, looks, palettes, glyph sets, particle effects, specs, `scripts/lib/`), the project's `flint.toml` and its schemas. Paths are the project's, so `?bundle=x.flintpack` plays the scene as it plays from the disk. `--name` and `--out-dir` work as for a game; `--scene` is refused. Separately, `flint check`, `flint bundle` and `flint export web` now read each `.glb`/`.gltf` and fail on a texture or buffer it names beside itself that isn't there (the player used to skip the whole model silently), and read a music `*.suite.toml` for the stems it names.
**What to do.** Nothing. If `flint bundle` now fails with `the model names <file>`, pack that file (or embed it in the `.glb`).
