### `flint frame show | diff | image`: read a frame capture from the command line (#1087)
**What changed.** A new top-level command reads the folder `flint render --frame-capture` writes, with no GPU, scene or schemas. `flint frame show <capture>` prints the summary: scene, adapter, size, GPU time by pass, draws, memory. Its views are `--passes`, `--draws [--pass P] [--entity E] [--sort tris] [--culled]`, `--targets` and `--hitch`. `flint frame diff <a> <b> [--out dir]` names the passes, entity draws, targets and pass images that changed between two captures. `flint frame image <capture> <pass> -o x.png` copies a pass's image out viewable: HDR tonemapped, depth to grey, ids coloured. Every view answers `--json`. A capture's manifest gains optional `scene`, `engine`, `written_by`, `captured_at`, `cpu` and `frame.game_time` fields. That is no version bump: older readers ignore them. A capture newer than the reader is refused, naming both versions.
**What to do.** Nothing. To debug a frame, capture it and run `flint frame show` on the folder.
