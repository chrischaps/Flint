### A glyph set's TTF needs only the ASCII it has; eleven new sets in `examples/fonts/` (#935)
**What changed.** A `*.glyphs.toml` naming a TTF or OTF used to fail unless the font had every printable ASCII character, which ruled out emoji, cuneiform and other fonts with no Latin letters. The atlas now takes the ASCII the font has; the glyphs the set's ramps and `[edges]` name must still all be there, and a missing one is still an error naming it. A set whose font has every ASCII glyph loads exactly as before. The examples gain eleven sets with OFL fonts and their licences beside them (`examples/fonts/ofl/`): `phosphor`, `typewriter`, `poster`, `geometric`, `stars`, `kana`, `brush`, `hangul`, `cuneiform`, `moon` and `runes` (book: concepts/glyph-atlas.md, "Sets in the examples").
**What to do.** Nothing. To use one in a game, copy its `.glyphs.toml` and its `ofl/<Family>/` folder (font and `OFL.txt`) into the game's `fonts/`. A font of another script wants `cell = 14` or more to read as letters.
