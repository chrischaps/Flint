### A package's flags on a command it doesn't own: `[provides] flags`, and `render --ai-refine` is the ai package's (#1572)
**What changed.** A package manifest has a seventh `[provides]` list, `flags`: each flag the package adds to (or serves on) another's command, as a line spells it (`"render --ai-refine"`, `"asset resolve --strategy ai_generate"`). A binary built without the package names it for one, exit 2 and `package` in the `--json` error, as it does for a command. `render`'s "Refine a look" group (`--ai-refine`, `--refine-rounds`, `--refine-candidates`, `--refine-out`, `--ai-provider`, `--ai-model`, `--max-cost`) is the ai package's now: a `flint` built without it has none of them in `flint render --help`, where before it listed them and refused them. In a stock build `--help` and every spelling are as they were. A game binary's `CliExtension` can add a flag group to `render` the same way (`CliExtension::flags`, `flint_package::cli::flags`).
**What to do.** Nothing.
