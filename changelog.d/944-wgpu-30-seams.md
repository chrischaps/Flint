### `flint_render::AcquireFrame`, `TrustedShader` and `SurfaceError`; wireframe lines unbiased on DX12 (#944)
**What changed.** Ahead of the wgpu 30 upgrade (#950), Flint's windows take their frame with `surface.acquire()` (`flint_render::AcquireFrame`), which returns `flint_render::SurfaceError` instead of `wgpu::SurfaceError`, and `SceneRenderer::render` now returns that type too. Flint's own WGSL modules are made with `device.create_trusted_shader_module` (`flint_render::TrustedShader`); user styles are unchanged. The overlay, skeleton and skinned wireframe line pipelines no longer carry a depth bias, which wgpu 29 rejects on lines. Vulkan applies no bias to lines and the web build never set one; on DX12 with an NVIDIA GPU the frames were byte-identical too, but another DX12 driver may lose a few pixels of a line to the surface it traces (Metal was not checked). `flint_debug_ui::run_headless_frame` runs an egui frame for a test and clears its texture updates.
**What to do.** If your code matches on `SceneRenderer::render`'s error, match `flint_render::SurfaceError` instead of `wgpu::SurfaceError`. A game with its own window can take frames with `AcquireFrame`, so the wgpu 30 bump won't touch that code.
