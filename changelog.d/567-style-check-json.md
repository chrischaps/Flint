### `flint style check --json` gives each error in parts; style paths print with `/` (#567)
**What changed.** Under the global `--json`, each entry of `styles` now carries `loops`, `bounded_loops` and `texture_reads` (`null` for a style that doesn't compile), `warnings`, and `errors`: one object an error with `file`, `line`, `col`, `message`, the quoted `source` line and `hints`. `error`, the whole text, is still there for a style that fails. On Windows, every path in a user style's messages (the check, the load errors, the in-game error card) and in `flint style new`'s output prints with `/`: `styles/x.wgsl:38:15` where it said `styles\x.wgsl:38:15`, and `demo/styles/x.wgsl` where it said `demo/styles\x.wgsl`. Elsewhere nothing moves.
**What to do.** Nothing. A script that read `error` keeps working; one that matched a `\` in a style's message on Windows should match `/`.
