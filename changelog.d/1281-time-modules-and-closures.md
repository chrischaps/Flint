### `--perf` and traces time imported module functions and closures (#1281)
**What changed.** While a callback is timed (`--perf`, F2, `--hitch-log`) or a trace records, an imported module's functions now get their own records, named as the import names them (`menu::is_open()`), and so do closures, named by file and line (`hud.rhai:closure at line 12`). In a trace each is a scope inside its caller's, so a slow `menu::` helper or `sort(|a, b| ..)` is no longer hidden in the callback's own time. With timing off nothing changes, in what runs or in what it costs.
**What to do.** Nothing. One thing to know: timing a module imports a second, timed copy of it, which runs the module's top level once more when timing first starts. A `log()`, sound or `random()` at a module's top level happens again then. See the book's Profiling guide, "Inside a script".
