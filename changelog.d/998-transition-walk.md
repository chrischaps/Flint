### `global::NAME` inside a method call's arguments works; transition checks walk the script (#998)
**What changed.** A top-level constant read inside a method call's arguments, as in `keys.push(global::GLOW)`, failed with "Variable not found: global::GLOW" since #1012: the scan that finds a script's `global::` reads skipped those arguments (Rhai's AST walk doesn't enter them). It now enters them, nested calls included. Whether a script may call `complete_transition()` (which decides if the player waits for a script to end a scene transition) is now found by the same AST walk instead of searching the AST's `Debug` text, about 100 times faster at each load and reload. A function whose name only contains the text, such as `complete_transition_soon()`, no longer counts as the call, so a scene with no real `complete_transition()` no longer waits out the 10 s timeout.
**What to do.** Nothing.
