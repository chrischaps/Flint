### `--compare` and `--split` are living's own flags; a package manifest's `[without]` (#1585)
**What changed.** `flint-player` and `flint play` take `--compare A,B` and `--split` from the living package (`flint_living::player::CompareArgs`, under a "Living props" help heading), so a player built without living has neither flag and refuses them, where it used to warn and play on. A package adds its own flags with `Registry::player_args::<A>()`; `flint_package::LaunchFlags` and `PlayerApp::launch_flags_mut` are gone. The "built without" line a scene hears is written from the package's manifest: ``[living] this player is built without the `living` package: the scene's living_prop, [wooze] stand still`` (it said "feature", and "living props"; woozy grass is no longer named, since it needs a `[wooze]` table). A manifest may have a `[without]` table: `does` (that line's ending) and `policies` (state names a game may use in every build).
**What to do.** A game binary that called `app.launch_flags_mut().set("compare", "a,b")` inserts `flint_living::player::CompareArgs { compare: Some(Presets { a, b }), split }` into `app.core.resources` before the first scene. A test that matched the old line's words matches the new ones.
