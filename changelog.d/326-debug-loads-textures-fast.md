### Debug builds load big models about 7x faster: copy the `[profile.dev.package.*]` overrides if your game has its own workspace (#326)
**What changed.** A debug build now optimizes what loads a texture: the PNG/JPEG decoders, glTF's JSON, SHA-256, and a new leaf crate, `flint-pixels`, that now holds the RGBA widening and the mip-chain box filter (`flint-render` calls it, and `flint_render::memoize_mip_chains` is unchanged). A debug `flint render` of `examples/style_mask.scene.toml` went from 19.3 s to 2.6 s (release: 2.1 s), with byte-identical pixels. Workspace crates stay unoptimized, so incremental rebuilds are as before.
**What to do.** If you build Flint through the engine's own workspace (`cargo run` in `engine/`, or a game crate that is a member of it), nothing. Cargo reads `[profile]` only from the root workspace, so a game whose own `Cargo.toml` is the root should copy the block under "A debug build optimizes what loads a texture" from `engine/Cargo.toml` into it.
