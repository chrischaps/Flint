### `flint bundle` packs only the packages `[packages]` lists, and a player knows only its own (#1529)
**What changed.** With a `[packages]` table in `flint.toml`, `flint bundle` packs and lists only the schema folders of the packages it lets in. A game that doesn't list `living` ships no `living_prop`, `shallow_wooze`, `[living]` or `[wooze]`. A packed scene that uses a left-out package is refused as an `unlisted-package` error, with the line to add as its hint, the same error `flint check` reports. A mistake in the list refuses the bundle. A project with no `[packages]` table bundles byte for byte as before. A player built or launched without a package no longer reads that package's schemas, from the disk or from a bundle, and the web player carries only the schemas of the packages it was built with. In such a player a `living_prop` is an `unknown-component` in the load summary.
**What to do.** Nothing, unless a bundle is refused: then add the line the hint names under `[packages]`.
