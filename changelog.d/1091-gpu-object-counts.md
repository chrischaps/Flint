### F2 and `--perf` count the GPU objects a frame creates, and the memory the renderer holds (#1091)
**What changed.** The renderer counts every buffer, bind group, texture, pipeline and shader module it creates and every buffer and texture write (`flint_render::gpu_counts`). F2's overlay shows `Alloc/frame` (amber when a frame created anything) and GPU memory by class; `--perf` and `?perf=1` add `gpu/frame create ...` and `gpu mem ...` parts; `--exit-after`'s report adds two `[perf]` lines; a frame that creates objects leaves a `gpu objects` frame note. `RenderStats` gains `gpu_calls`, `gpu_memory` and `device_memory`, and `SceneRenderer` gains `frame_gpu_calls()`, `gpu_calls_reading()` and `gpu_memory()`. Inside flint-render the bare `device.create_buffer` and friends are refused by its own `clippy.toml`: use `CountedDevice` / `CountedQueue`.
**What to do.** Nothing. A game that builds a `RenderStats` literal adds `..Default::default()`; a game's own Rust that calls wgpu directly is not counted.
