### `flint init` projects have a pause menu; a click no longer catches the cursor while paused (#1228)
**What changed.** Every template (`walk`, `blank`, `2d`) writes `ui/pause.ui.toml` and `ui/pause.style.toml`, binds `pause` to Escape and a pad's Start in `config/input.toml`, and its `scripts/hud.rhai` opens the menu with `import "menu"` (Resume, Restart, Quit; a pause button on a touch screen). With `--engine path` or `none` the project carries `scripts/lib/menu.rhai`, a copy of the engine's, since `import` doesn't search a checkout named by path. In the player, a left click in a first-person scene no longer catches the cursor while the game state pauses physics (the `paused` state `menu::toggle_pause` pushes), so a click in a pause menu stays the menu's.
**What to do.** Nothing for an existing game. A first-person pause menu that relied on a click to catch the cursor again calls `set_cursor_captured(true)` when it closes. A project made by an older `flint init` can take the menu from a fresh `flint init x` beside it.
