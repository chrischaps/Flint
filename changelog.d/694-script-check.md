### `flint script check`, and `flint check` / `flint validate` now fail on a script error (#694)
**What changed.** `flint script check [dir | scene | file.rhai] [--json]` compiles every script and the modules it imports, and reports at `file:line:col` a syntax error, a call of a function that isn't there (with the nearest name), a call with an argument count it doesn't take, a literal no declaration accepts, an `fn on_colision` that is no callback, a callback with the wrong parameters and an import that finds nothing. `flint check` and `flint validate` (and so `flint examples --check`) run the same pass, so a script error now fails them. Diagnostics' JSON gains `line` and `column`. The showcase pause menu's `draw_line` calls passed 8 arguments of 9 and never drew; fixed.
**What to do.** Run `flint script check` and fix what it finds. A function your game binary's extension registers isn't in the engine's API: pass `--allow <name>` for each, or `--api <file>` with your binary's own listing (`app.script.api_listing()` written in `flint script api --json`'s shape), to all three commands.
