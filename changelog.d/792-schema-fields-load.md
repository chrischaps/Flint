### `collider`, `rigidbody` and nine other schemas load their fields; a schema file with keys outside `fields` fails; `audio_listener` is gone (#792)
**What changed.** Ten engine schemas (`collider`, `rigidbody`, `character_controller`, `audio_source`, `audio_trigger`, `joint`, `parallax`, `screen_anchor`, `ui_fill`, `ui_text`) declared their fields under `[component.x]` and loaded with none. They now load, so `flint validate` checks them: `collider.shpae` warns, `rigidbody.body_type = "dynamc"` is an error, and `screen_anchor.anchor`, `ui_fill.direction` and `ui_text.align` are enums. Their defaults are written in at load and each equals the reader's fallback, so nothing plays differently. A component schema file with any key under `[component.x]` besides `description` and `fields` now fails to load, naming the file and keys. `audio_listener` is deleted: nothing read it, since the listener is the camera, and the `player` archetype no longer lists it.
**What to do.** Run `flint validate` on your scenes. Delete any `[entities.x.audio_listener]` table, which now warns as an unknown component. If one of your own schema files fails to load, move its fields under `[component.<name>.fields]`.
