### Skeletons, node clips, IK and the model previewer are the `rig` package's: `rig = false` drops them (#1621)
**Package.** rig
**What changed.** Skeletal and node clips, layer blending, two-bone IK (`ik_two_bone`), bone probes (`bone_probe`), the `skeleton` component and the model previewer (`flint edit <model>.glb`) moved from `animation` to the new standard package `rig` (`packages/rig/crates/flint-rig`, ADR 0139), which requires `animation`. A game writing `rig = false` links no skeleton, IK or glTF clip code; a scene that still uses them hears once that they stand in their rest pose. `animation = false` now needs `rig = false` beside it. Every frame plays as before. For a game's Rust: the skeletal calls on `AnimationSystem` are the `flint_rig::Rig` trait's, `ClipKinds` holds `KindEntry`s, `CapturePose` gains `settle`, `upload`, `time` and `report`, and `flint render --anim-time` makes its pose through the `CapturePoses` point.
**What to do.** A project that writes `animation = false` adds `rig = false`. A game binary calling skeletal methods on `AnimationSystem` adds `use flint_rig::Rig;`.
