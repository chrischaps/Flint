### One hash and value noise for every style; `flint_vnoise` and the mask readers in the user prelude (#1256)
**What changed.** Pencil, contour, Kuwahara, watercolor and ASCII's dissolve now boil and grain with one integer hash (PCG) and one value noise, `stylize/noise.wgsl`, and every style reads the style mask through one reader. Pencil's looks are unchanged; contour's and Kuwahara's boil, watercolor's paper and blotches, and the order an ASCII dissolve turns its cells in are new patterns of the same character (the dissolve's was a `sin()` hash that read differently GPU to GPU). A user style's `flint_hash(v)` now hashes the vector's bits with the same PCG, so it returns other values (still a stable 0..1, now also far from the origin), and the prelude adds `flint_hash1(x, y, seed)`, `flint_hash3`, `flint_vnoise(p, seed)` and, with `inputs = ["mask"]`, `flint_mask_load`, `flint_mask_blend` and `flint_mask_texel_of`.
**What to do.** Nothing, unless a user style defines a function of one of those names: rename yours. A style tuned against `flint_hash`'s exact values will see a different (equally random) pattern.
