### `flint render --set post.<key>=v` replaces the per-effect flags; `--help` is grouped (#708)
**What changed.** `--set` sets one key as a scene writes it: `post.<key>=v` for any `[post_process]` key (`flint render --list-effects` lists them), or `<style>.<key>=v` for a style's table, leaving the style on or off as it was (`--style` turns it on). The 70 per-effect flags (`--exposure`, `--bloom-intensity`, `--fog-*`, `--kuwahara-*`, `--contour*`, `--ascii*`, `--tear*`, `--fxaa`...) still work for this release, hidden from `--help`, and each prints its new spelling: `--fog-density 0.05` is `--set post.fog_density=0.05 --set post.fog_enabled=true`. They go in the next release. `--ascii-cell`, `--ascii-levels`, `--ascii-footprint`, `--ascii-edge-depth`, `--ascii-edge-normal` and `--ascii-no-edges` now tune the ASCII style's table even when it's off, as `--set ascii.<key>` does. `flint render --help` is grouped by heading.
**What to do.** Change scripts, variant files and goldens that call `flint render` with the old flags to the printed spelling. A Rust host that builds `RenderArgs` reads its flags by group now (`args.camera.distance`, `args.clock.time`).
