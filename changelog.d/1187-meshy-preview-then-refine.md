### `flint asset generate model --provider meshy` makes a preview, then refines it (#1187)
**What changed.** A Meshy model was one request, a refine with a prompt and no `preview_task_id`, which Meshy's v2 API refuses. It is now the two the API asks for: a preview of the prompt, polled until it succeeds, then a refine of it with `preview_task_id`, polled and downloaded. Each is its own line in `.flint/ai_costs.jsonl` (`openapi/v2/text-to-3d preview`, 20 credits; `... refine`, 10), and the built-in price is `[calls.meshy] unit = "credit"`, `usd = 0.02`, so a model still costs $0.60. A job record names both tasks: `remote_id` is the preview, the new `refine_id` the refine once submitted; `flint asset job resume` goes on from either, and a job stopped in its preview pays for the refine alone (its ledger line says `"operation": "resume"`). A style guide's negative prompt is no longer sent to Meshy (the v2 API takes none); the refine asks for PBR maps (`enable_pbr`).
**What to do.** Nothing, if `.flint/prices.toml` doesn't price Meshy. One that does as `unit = "task"` keeps working (the price is split 2:1 between the two requests); to price by the credit, write `unit = "credit"` and your plan's rate a credit.
