### Particles are a package a game can leave out: `particles = false` (#1622)
**Package.** particles
**What changed.** Particle emitters, effects, the `particle` script module, the F3 Particles panel and the effect editor are the `particles` package (`packages/particles/`), a standard package: a game that writes nothing still has them, and every frame, capture and golden draws as before. With `particles = false` under `[packages]`, `flint build` links no `flint-particles` into either binary. A scene's emitters then emit nothing (said once at its entry), `flint check` names the package (`unlisted-package`) for a `particle_emitter` or `particle_effect`, and `flint edit <x>.particles.toml` and `flint render --particle-time` name it too. A game state may still name the `particles` policy. For Rust: `GameCore::particles` is gone (the system is the run's resource, `flint_particles::of_mut(&mut core.resources)`), so is `flint_runtime::state::PARTICLES`, and the four particle `ScriptCommand` variants are the package's module commands.
**What to do.** Nothing, unless a game's own Rust read `app.core.particles`: read the resource instead.
