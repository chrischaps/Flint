### `ocean.tint_preset` picks the sea's tint by name: `blood` or `underside` (#1035)
**What changed.** The `ocean` component has a `tint_preset` key, `"blood"` (the default) or `"underside"`, that the `tint_*` fields fall back on when unwritten, so a script switches the sea between the crimson tide and the surface seen from below with one `set_field` and drives `tint` alone. The `tint_*` fields no longer carry a schema default: a load wrote it into the component, where it would beat the preset. A scene or script that writes them reads as before, and one that writes none draws the crimson tide as before. A script's `get_field` of an unwritten `tint_*` field now returns `()` instead of the crimson tide's value.
**What to do.** Nothing. To show the underside that `set_render_mode(5, ..)` drew, set `tint_preset = "underside"` and `tint` to the dunk's mix (with the `underwater` style on); have one script own the tint fields.
