### DXC is linked into Windows builds; `flint dxc install` and `FLINT_DXC_DIR` are gone (#947)
**What changed.** DX12's shader compiler is now built into the binary on x86_64 Windows with MSVC: Microsoft's DXC v1.9.2609, built from Microsoft's source by Flint's `static DXC` workflow. flint-render's new default feature `static-dxc` links it. No `dxcompiler.dll` or `dxil.dll` ships, and DX12 takes wgpu's `Dx12Compiler::Auto`. The adapter line reads `DXC (static, v1.9.2609)`. `WGPU_DX12_COMPILER` is read by wgpu now, so `fxc` still forces FXC, and `dxc` loads `dxcompiler.dll` by name. The first build on a machine downloads an 80 MB archive once into `%LOCALAPPDATA%\flint\static-dxc`. Offline, set `FLINT_STATIC_DXC_ARCHIVE` to a copy of it. Linking needs MSVC 14.44 (Visual Studio 2022 17.14) or newer.
**What to do.** Drop `flint dxc install` from your build scripts, and the DLLs and `dxc-LICENSE-*.txt` files from your Windows builds. Ship `flint dxc notices --to <build folder>` (`THIRD-PARTY-NOTICES-DXC.txt`) beside your game's executable instead.
