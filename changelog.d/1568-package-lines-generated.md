### `package.toml` takes `[rust.devices]`, and every package's launcher lines are generated (#1568)
**Package.** engine
**What changed.** `scripts/package-sync.py` now writes all six engine packages' features and dependencies in `crates/flint-player/Cargo.toml` and `crates/flint-cli/Cargo.toml`, not just a new package's. Two manifest tables feed it. `[rust.devices]` names the package's crates' device features for the launchers' `audio`, `gamepad` and `dialogs` (`audio = ["flint-music/device"]`). A device feature turns on a generated `packages-<device>` that holds them. `[with.<other>] features` lands on the other package's feature. Each build turns on the same crates with the same features as before.
**What to do.** Nothing, unless you change an engine package's lines in those two files: edit its `package.toml`, run `python3 scripts/package-sync.py`, and keep the hand-written `audio`, `gamepad` and `dialogs` turning on their `packages-*` feature. The script refuses a package's feature written by hand.
