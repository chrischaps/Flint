### `flint edit` saves a `.procgen.toml` without losing its comments (#194)
**What changed.** `Ctrl+S` and `Ctrl+Shift+S` in the procgen previewer, and `Ctrl+S` in the texture pipeline editor, used to rewrite the whole spec with `toml::to_string_pretty`. That dropped every comment and sorted the keys alphabetically. Now they patch the file you opened. A changed value is replaced on its own line and keeps its trailing comment. A key the editor drops moves the comment above it to the next key. A new key goes at the end of its table. A save with nothing changed leaves the file byte for byte, and CRLF files stay CRLF. The node editor no longer writes the defaults it fills in, or an `id` and `inputs` on every op, unless the file used them or the graph needs them. Specs an earlier save already flattened stay as they are.
**What to do.** Nothing.
