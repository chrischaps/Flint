### Scope traces on the web, measured: `?scope_bench=1`, `run.mjs --save-trace` and `--isolate` (#1266)
**What changed.** A web build with the scope recorder (`trunk build --release --cargo-profile web-release --features trace`) was played in Chrome and Firefox: `?perf=1`'s Save trace downloads a trace Perfetto and `flint profile` open, and its header now says when it was saved (`written_at` was empty on the web). A recorded scope costs about 120 ns in a browser (30 ns natively), nearly all of it `performance.now()`. On a page that isn't cross-origin isolated the clock steps by 100 µs (Chrome) or 1 ms (Firefox), so most scopes read 0 ms; a scope's mean over many frames still reads true, one frame's tree and self times don't (the book's Recording a trace). The page's new `?scope_bench=1` times a scope in the browser it runs in and leaves the numbers in `window.flintScopeCost`; `flint_core::profile::cost::measure` is that bench, for any host. `tools/web-perf/run.mjs` gains `--save-trace` (presses Save trace and keeps the file, summed up by `scopes.mjs`) and `--isolate` (serves COOP/COEP), keeps `?scope_bench`'s numbers, and no longer leaves Firefox running after a run on Windows. A trace's GPU passes no longer overlap by a nanosecond, which Perfetto counted as an import error each frame.
**What to do.** Nothing.
