### Every `flint` command takes `--json`, and failures exit 1 (#710)
**What changed.** `--json` is now a global flag: every command that opens no window prints exactly one JSON document on stdout and sends its other lines to stderr. A failure exits 1, with the command's report (`"valid": false`) or `{"error": {"message", "causes"}}` still on stdout; a command-line mistake is an error document with exit 2. Window commands (`play`, `edit`, `prefab view`, the music windows) refuse `--json`. One command that exited 0 on a failure now exits 1: `asset resolve --strategy ai_generate|human_task|ai_then_human` now exits 1 when a reference could be neither generated nor handed to a person. `--format json` (validate, query, entity, schema) and `render --report json` still work and are what `--json` prints. `gen --report json` still prints a JSON line a variant; under `--json` they are one document's `variants`. Some progress lines that were on stdout are now on stderr (`asset resolve`'s batch lines, `Loaded skybox`, `Warning: No schemas directories found`).
**What to do.** A script that parsed a command's text can read its `--json` document instead. A script that read a progress line from stdout reads stderr.
