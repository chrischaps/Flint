### The ai package's crates live in `packages/ai/crates/` (#1554)
**What changed.** `flint-asset-gen`, `flint-procgen-ai` and `flint-ai-core` moved from `crates/` to `packages/ai/crates/`, beside the package's `package.toml`. The engine's workspace takes every `packages/*/crates/*` as a member. A manifest can now name the crate that brings its CLI commands, `[rust] cli = "<crate>"`, and `flint`'s build lists that crate's commands from it. Commands, flags and `--help` are as they were: `flint asset generate` and the other five work as before, and a flint built without `ai` still names the package for them.
**What to do.** If your game depends on one of these crates through the engine's workspace (`flint-asset-gen = { workspace = true }`), nothing. If it names one by path, change `engine/crates/flint-asset-gen` (or `flint-procgen-ai` or `flint-ai-core`) to `engine/packages/ai/crates/<crate>`.
