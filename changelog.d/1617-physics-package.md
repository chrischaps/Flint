### Physics is a package: `physics = false` builds a game without Rapier (#1617)
**Package.** engine
**What changed.** `flint-physics`, the `collider`, `rigidbody` and `joint` schemas and the `physics`, `physics_2d` and `nav` script modules are the `physics` package's (`packages/physics/`), a standard package that is on unless `[packages]` says `physics = false`. With it off, the player and CLI link no Rapier, and a scene's `collider` is `unlisted-package`. `get_joint_position` is in the `physics` module now. For a game's own Rust: `GameCore::physics()` / `physics_mut()` are gone (`flint_physics::of(&core.resources)`), `ScriptSystem::state_scope` takes `&Resources`, `Call::physics()` is `call.resource::<PhysicsSystem>()`, `ScriptCommand::SetVelocity2D` is the package's module command, and `Subsystem` gains `step(StepStage, ..)` (its default still calls `fixed_update`), `chunk_loaded` / `chunk_unloading`, and `Stage::View`.
**What to do.** Nothing for a game that writes no Rust. A game binary renames the calls above; a game with no bodies can add `physics = false`.
