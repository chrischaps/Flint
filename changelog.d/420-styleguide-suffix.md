### AI style guides are `styles/<name>.styleguide.toml`, not `.style.toml` (#420)
**What changed.** The style guides `flint asset generate --style`, `flint asset validate --style`, `[generation] style` and `flint gen --validate --style-guide` read now use the suffix `.styleguide.toml`. `.style.toml` stays what it also was: a UI class file beside a `.ui.toml` layout, which is unchanged. The engine's `styles/medieval_tavern.style.toml` is now `styles/medieval_tavern.styleguide.toml`. A guide still named `<name>.style.toml` loads, with a warning naming the file to rename it to; when both names exist the new one wins. A later release stops reading the old name.
**What to do.** Rename your own guides: `git mv styles/<name>.style.toml styles/<name>.styleguide.toml` (and under `.flint/styles/`). Scripts or CI that pass `--style-guide styles/medieval_tavern.style.toml` take the new path. UI `.style.toml` files need nothing.
