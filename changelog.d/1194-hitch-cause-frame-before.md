### A hitch's `cause` names a script that stalled, not the frame before's slow note (#1194)
**What changed.** The hitch log's `cause`, `--perf`'s hitch line, F2's graph and the exit report's `causes:` named a frame's notes whenever, with the frame before's, they covered half its excess. On a loaded machine a 100 ms reload poll on the frame before outvoted a 150 ms script stall on the frame itself, which read `reload poll 1 scripts watched, 111.7 ms (frame before)`. When the hitch's own script took half its excess, the frame before's notes no longer count toward it: the line reads `script stall.rhai:on_update 150.0 ms (also: reload poll 111.7 ms the frame before)`. Notes on the hitch's own frame count as before.
**What to do.** Nothing. A `--max-hitches` gate counts the same hitches; only their causes are named differently.
