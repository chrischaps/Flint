### F1 lists the debug keys in every `flint edit` editor; the procgen previewer's debug-mode cycle moves to F5 (#1170)
**What changed.** The editors' function keys are a debug key table like the player's: F1 shows the same card in the scene viewer, the track editor, the procgen previewer and every other editor, listing the host's F1 and the editor's own keys. In the procgen previewer F1 used to cycle the debug shading mode; that is F5 now (F2 wireframe, F3 normal arrows and F4 skeleton keep their keys). A held F-key no longer repeats its toggle. A game binary that paints the card itself calls `flint_runtime::debug_key_card::paint` (the runtime's new `egui` feature); `flint_viewer::host::Editor` gained `debug_keys`, `debug_keys_live` and `on_debug_key`.
**What to do.** Press F5, not F1, for the previewer's debug modes. An `Editor` of a game's own declares its F-keys in `debug_keys` instead of matching them in `event`.
