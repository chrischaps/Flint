### The music commands are `flint music ...` now (#709)
**What changed.** The six rhythm tools moved under one command: `validate-suite` is `flint music validate`, `play-suite` is `music play`, `render-suite` is `music render`, `calibrate` is `music calibrate`, `play-chart` is `music chart play` and `replay-chart` is `music chart replay`. Their flags are unchanged. The old names still run for one release, each printing its new spelling on stderr, and are no longer listed in `flint --help`; `render-suite <x>.goldens.toml` still runs `flint goldens`. The rumble spike (ADR 0025) is an example program now, `cargo run -p flint-input-capture --example spike_rumble`; `flint spike-rumble` still runs it for one release. The calibration notice says `flint music calibrate`.
**What to do.** Change scripts, CI jobs and docs that call the old names to the new ones before the next release removes them.
