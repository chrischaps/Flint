### `find_entities_with`, `get_children`, `overlap_rect` and `persist_keys` return the same order every run (#689)
**What changed.** The three functions that return entities now return them sorted by entity name, and `persist_keys` returns its keys sorted. They used to come in hash-map order, which changed from one run to the next, so `find_entities_with("enemy")[0]`, or a loop that spawned, played a sound or drew for each result, differed between two runs of the same scene and broke the byte-identical promise of `flint render --scripts` and `--frame-step` captures. `FlintWorld::get_children` (Rust) is name-ordered too and is now a lookup in a children index rather than a scan of every entity; `FlintWorld::in_name_order(ids)` sorts any list the same way, and `get_name` is a lookup.
**What to do.** Nothing, unless a script relied on a particular order it happened to get: name entities for the order you want (`wave_01`, `wave_02`), or sort the array in the script.
