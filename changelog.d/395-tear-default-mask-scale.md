### A reality tear with no `mode_params` tears in patches (#395)
**What changed.** Render modes 1-4 read `mode_params.x` as the bleed mask's scale, and the config defaults it to 0. At 0 the noise was one value over the whole screen, so a partial `mode_mix` tore all of the frame or none of it. At `--mode-mix 0.55` with no params, the frame came out untouched. The shader now reads a scale of 0 or less as the default 3, the same way Matrix already reads a rate of 0 as 6. So `set_render_mode(1, 0.55)` with no `set_render_mode_params`, the F4 menu's starting values and `flint render --render-mode 1 --mode-mix 0.55` all draw drifting patches. They match `3, 0, 6, 0` byte for byte. Any positive scale draws exactly as before, and mode 5 (underwater, where `x` is eye depth) is untouched.
**What to do.** Nothing. A game that wants the whole frame to turn at once should drive `mode_mix` to 1, or use the radial iris (`y = 1`).
