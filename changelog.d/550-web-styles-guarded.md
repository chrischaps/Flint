### A user style's runaway loop no longer loses the device in the browser (#550)
**What changed.** `flint bundle` (and `flint export web`) now packs a loop-guarded copy of each user style pass that has a loop to guard: `styles/<style>.guarded.wgsl`, or `styles/<style>.<pass>.guarded.wgsl` for a style with `[[passes]]`, beside its `.shader.toml`. The web player builds that copy, as the native build has since #411, so a loop that never ends stops after 4096 turns and draws a wrong pixel instead of losing the GPU. A style without loops, or with only constant-bounded `for` loops (#424), packs nothing extra. The copy records a hash of the text it was made from, and the browser passes over a copy made from another version of the WGSL or the engine.
**What to do.** Bundle again to get the guard on the web. If your game already has a file at one of those names, rename it: `flint bundle` refuses to overwrite it.
