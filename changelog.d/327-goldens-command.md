### `flint goldens`: golden image suites have their own command (#327)
**What changed.** A `*.goldens.toml` runs with `flint goldens <manifest>` and its flags (`--bless`, `--bless-variant`, `--bless-drifted`, `--case`, `--out-dir`, `--require-gpu`, `--isolate`); `flint goldens --help` lists only those. `flint render-suite` is the music suite's alone again: its help lists only the music flags, and `--output` is required by the parser (a missing one exits 2 with clap's usage line instead of a runtime error). The old spelling, `flint render-suite <x>.goldens.toml` with any golden flags, still works and runs the same command, so scripts and CI jobs that use it need no change. The suite's first line now reads `goldens '<name>': ...` and the contact sheet's heading `flint goldens`; `report.json` is unchanged.
**What to do.** Nothing. Prefer `flint goldens` in new scripts and docs.
