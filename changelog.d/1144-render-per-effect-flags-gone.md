### `flint render`'s per-effect flags are gone: write `--set` and `--style` (#1144)
**What changed.** The 67 flags #708 hid for a release (`--exposure`, `--bloom-intensity`, `--fog-density`, `--kuwahara-radius`, `--contour-width`, `--ascii-ramp`, `--ascii-cell`, `--tear`, `--fxaa` and the rest) are no longer flags. A command line, `--variant` or golden case that gives one fails before drawing, with clap's exit code 2 and an error listing every old flag on the line beside what to write, for example `--exposure 1  ->  --set post.exposure=1` and `--fog-density 0.05  ->  --set post.fog_density=0.05 --set post.fog_enabled=true`. The deprecated `--render-mode`, `--mode-mix` and `--mode-params` (#746) still work; #1036 removes them.
**What to do.** Run each render line in your tools, scripts, variant files and docs once, and paste in the spelling the error prints. The rules: a `[post_process]` key is `--set post.<key>=v` (`flint render --list-effects` lists them). A strength that used to switch its effect on also needs the switch: `post.bloom_enabled`, `post.fog_enabled`, `post.fog_height_enabled`, `post.dither_enabled` or `post.volumetric_enabled`. A flag that turned a style on is `--style <style>:<key>=v`, with colours written `r/g/b`. A flag that only tuned a style is `--set <style>.<key>=v`: `--set ascii.cell=12`, `--set kuwahara.boil=0.5`.
