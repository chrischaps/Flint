### `PlayerExtension::ui` takes the frame's root `&mut egui::Ui` (#959)
**What changed.** The game UI hook takes the root `egui::Ui` that egui 0.36's `Context::run_ui` hands out, the shape of eframe's `App::ui` (ADR 0121). Panels show on it (`egui::Panel::left("inv").show(ui, ..)`) and windows and areas from it (`egui::Window::new("Quests").show(ui, ..)`: a `Ui` derefs to its `Context`). An extension with `fn ui(&mut self, ctx: &egui::Context)` no longer compiles. `root_ui(&mut egui::Ui)`, added by #946 for panels, is deprecated; the player still calls it, and its default calls `ui`, so a game overriding it draws as before.
**What to do.** Change `ui`'s parameter to `ctx: &mut egui::Ui` (or `ui: &mut egui::Ui`). The body compiles as it was: `show(ctx, ..)`, `ctx.input(..)`, `ctx.clone()` and passing `ctx` as a `&egui::Context` go through the `Deref`. Rename a `fn root_ui` to `fn ui`; rustc doesn't warn about it. Book: Upgrading the Engine, "The game UI hook".
