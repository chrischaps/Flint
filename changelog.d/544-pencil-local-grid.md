### Pencil `grid = "local"`: strokes that ride on moving props (#544)
**What changed.** `pencil_style` (and the pencil table, `--style pencil:grid=local`) takes a fourth `grid`, `local`. It lays the same strokes as `grid = "world"` on the surfaces, but in the styled root's own space, so they ride on a prop that rolls, slides or turns instead of the prop moving under them; children that move with the root ride too, and a prop held on twos (`motion_hold`) keeps its strokes between drawings. A skinned mesh still swims under them. On the whole frame's table, which has no root, `local` draws as `world`. Nothing else moves: every existing pencil picture is byte-identical. Pencil's variant row grew from 160 to 208 bytes, which only a game reading `flint_render::stylize::pencil::PencilRow` sees. Demo: `examples/pencil_rolling.scene.toml`.
**What to do.** Nothing. For a prop that moves through the world, set `grid = "local"` on its `pencil_style`.
