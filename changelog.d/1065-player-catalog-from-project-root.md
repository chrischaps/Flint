### The player reads the asset catalog from the project root (#1065)
**What changed.** The player looks up a `model.asset`, `material.texture` or `sprite.texture` name in `<project root>/assets/*.asset.toml` and loads it from `<project root>/.flint/assets`, the catalog `flint validate` and `flint check` ask. It used to read `assets/` and `.flint/assets` in the working directory, so a game played from anywhere but its root loaded its catalogued models as missing (or, from an engine checkout, the engine's catalog), though it validated clean. A transition into another project reads that project's catalog.
**What to do.** Nothing, unless a game relied on a catalog in the working directory that isn't its project's: move it under the project root (the folder holding `flint.toml`), or pass `--project <dir>`.
