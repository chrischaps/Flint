### `flint package used` names `procgen = false` when nothing uses procgen (#1536)
**What changed.** A standard package is in unless `[packages]` sets it to `false`, so a list of only what the files use still gave every game procgen, and with it the wooze field, in its player. Now, when the scan finds no use of a standard package it could have seen (procgen: a spec name or a `*.procgen.toml` path), `flint package used` prints the line that leaves it out, `procgen = false   # nothing scanned uses it`, under `[packages]`, and its JSON lists it in `leave_out` (`name`, `line`). `--write` never writes that line, because it changes what `flint build` gives a game. `debug-hud` is never named, since no file can show the F3/F4 panels in use. A package a listed one requires (`living` and `ai` need procgen) isn't named either.
**What to do.** To give a game that uses no procgen a player without it, add the printed `procgen = false` under `[packages]` in `flint.toml`, then run `flint build`.
