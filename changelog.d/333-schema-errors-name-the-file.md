### A schema file that doesn't parse names itself (#333)
**What changed.** A `components/*.toml` or `archetypes/*.toml` file of any schema directory that isn't valid TOML used to stop every command (`flint render`, `play`, `validate`, the player) with the parser's message alone: `TOML parse error: TOML parse error at line 2, column 21 ... expected newline, #`, and no file. The error now starts with the file's path, as a `scene/*.toml` table file's already did: `TOML parse error: schemas/components/style_mask.toml: TOML parse error at line 2, column 21 ...`. Files that load are unaffected. The engine's own schema files are now held by a test that loads each one (`crates/flint-constraint/tests/schema_files.rs`).
**What to do.** Nothing. A script that matched the old message text should look for `TOML parse error` and the file's path instead.
