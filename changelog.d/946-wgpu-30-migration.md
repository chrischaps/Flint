### wgpu 30 and egui 0.36: the port for a game's Rust, `PlayerExtension::root_ui` for panels, naga's new error wording (#946)
**What changed.** The book has the port from wgpu 23 and egui 0.30 ([Upgrading the Engine](https://docs.chaps.dev/guides/upgrading-the-engine.html)). egui 0.36 shows panels on a `Ui`, so `PlayerExtension` gains `root_ui(&mut egui::Ui)`, the frame's root `Ui`; its default calls `ui`, so existing extensions are unchanged. User style errors read in naga 30's words (``identifier: `x` `` for `'x'`), with the same file, line and hints: the `[images.<name>]` hint now follows the identifier, not the wording. `pack2x16float`, `unpack2x16float` and `quantizeToF16` pass `flint style check`. egui sends modifier keys (`Key::ShiftLeft`) as key events.
**What to do.** Scenes, scripts and user styles: nothing. A game's own Rust: follow the page. Move `SidePanel` / `TopBottomPanel` code to `egui::Panel` in `root_ui`, add `@interpolate(flat)` to integer varyings, and know that a `stylize::kit` style is trusted code with loop bounding off, so its loops must end (`FLINT_SHADER_CHECKS=all` turns bounding on).
