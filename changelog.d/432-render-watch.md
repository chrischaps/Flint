### `flint render --watch` writes the PNG again on every save (#432)
**What changed.** `flint render <scene> -o shot.png --watch` keeps running after its first render and writes the same output (a still, or a `--sweep` sheet) again whenever the scene's folder, its `styles/` folders, its schemas or a file a flag names (`--look`, `--variants`, `--reference`, `--camera-path`, `--expression-timeline`) changes. A save of a user style's `.wgsl` is drawn on the renderer that drew the last frame, about 0.15 s from save to PNG on a small scene, where a fresh `flint render` takes over a second; other saves load the scene again on the same GPU. Each render prints `watch: render <n> in <s> s (...)` and then every user style's error. Hosts that draw one frame a save can call `flint_render::stylize::custom::poll_files_now()` so a user style's pass looks at its files at the next draw instead of after 15.
**What to do.** Nothing. To tune a style headless, add `--watch` and save; Ctrl-C stops it.
