### `texture_v1`'s colour defaults name the colours it renders (#1165)
**What changed.** The schema, `flint edit`'s previewer and the README showed a colour default as the bytes of its linear floats, which parse to a far darker colour: `base_color`'s `#735A47` renders on average 69 levels (of 255) darker than leaving the key out, and the same went for `mortar_color` (`#40382E`) and for the pipeline ops `cell_color` and `mortar_color`. They now read `#B3A090` and `#898176`, the sRGB hex that parses back to the default (to within one level). `height_variation` no longer shows `0.3` for `tiling_grid`, whose default is 0.2; its description gives both. A spec renders byte for byte as before, whatever it says.
**What to do.** A spec saved from the previewer with `base_color = "#735A47"` or `mortar_color = "#40382E"` and meant to keep the default: delete the key, or write the new hex.
