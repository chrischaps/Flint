### A `profiling` Cargo profile for sampling profilers (#1101)
**What changed.** The engine's root `Cargo.toml` has a `profiling` profile: release's code with line tables in every crate, dependencies included. `cargo build --profile profiling -p flint-player` writes `target/profiling/`, which Superluminal, samply, WPA and Visual Studio's collector name function by function and line by line, inlined frames included. A cold build of the player takes about 4 minutes and 2.7 GB. The book's Profiling guide has a new section, "When scopes aren't enough", that covers which tool to use, the commands on Windows and Linux, and how to find a hitch from the hitch log on a sampler's timeline.
**What to do.** Nothing. For the same build of a game binary, copy the three lines of `[profile.profiling]` into the game workspace's root `Cargo.toml`. Cargo reads profiles only from there.
