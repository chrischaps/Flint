### The F2 overlay's last-hitch line now says what the hitch log says (#1128)
**What changed.** The line under the F2 frame-time graph used to work out a hitch's cause by itself, and it ignored frame notes. On the frame where a style's pipelines were built, it said `last 154 ms: script ui +156` while the hitch log said `style build ascii, 154.2 ms`. Now it is the hitch's time followed by the same `cause_line` the hitch log, the exit report and `--perf` print: `last 269 ms: style build ascii, 255.2 ms`, `last 117 ms: script stall.rhai:on_update 100.0 ms`, `last 30 ms: render +14.0 ms`, `last 13 ms: elsewhere, present 1.0 ms`. Times carry one decimal, as they do in the log. A slow `on_draw_ui` is now named as a script too, not as the `script ui` phase.
**What to do.** Nothing. If you compare an overlay screenshot against the old wording, update the expected line.
