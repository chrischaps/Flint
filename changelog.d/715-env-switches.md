### `flint env` lists every `FLINT_*` switch, and a bad value warns (#715)
**What changed.** Every `FLINT_*` environment variable the engine reads is now in one table (`flint_core::env`). `flint env [--json] [--group g] [--set]` prints each with what it accepts, what unset means and its value in this shell, and exits 1 when one holds a value it can't take. `flint render`, `flint play` and `flint-player --help` end with the switches they read, and the book has a page of them (CLI Reference, Environment Switches). A value a switch doesn't accept (`FLINT_VSYNC=fasle`, `FLINT_FRAME_LATENCY=5`, `FLINT_LOD_SCALE=0`) used to be ignored or clamped in silence; it now warns once, naming the forms it takes, and the default is used. `FLINT_GPU_LABELS` with an unknown word, once the per-draw level, is now a warning and the default.
**What to do.** Nothing, unless a script sets a switch to a value outside its range: run `flint env` to see. Engine code reads a switch through its getter (`flint_core::env::VSYNC.choice()`), never `std::env::var`.
