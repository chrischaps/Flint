### `blend_source = "field"`: a prop's style follows a screen field your scripts fill (#859)
**What changed.** `blend_source` on a style component (`ascii_style`, `pencil_style`, a user style's `<name>_style`) or a `style_mask` takes a third value, `"field"`. The entity's blend is then its `blend` times the **style field** at each pixel. The style field is a screen field that scripts fill each frame with the new `style_field` module: `field_disc(x, y, radius, soft[, strength])`, `field_ring(x, y, radius, width, soft[, strength])` and `field_cone(x, y, direction, spread, length, soft[, strength])`, in logical points, with angles in degrees clockwise from up. Like the draw calls, it is immediate mode: a frame that draws no shape has no field, and a prop following it draws as at blend 0. Each frame holds 16 shapes at most. A host that builds `flint_render::FrameInputs` by hand gets a new field, `style_field` (`&[]` by default). `"own"` and `"tear"` are unchanged, and a whole-frame style's table still takes only those two.
**What to do.** Nothing. To use it, see `examples/ascii_shockwave.scene.toml` and the book's "A blend that follows a screen field".
