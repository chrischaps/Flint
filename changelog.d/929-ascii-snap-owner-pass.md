### ASCII's cell silhouettes are decided once a cell: the glyph shader compiles in about a second on FXC (#929)
**What changed.** Which snapping variant (`silhouette = "cell"`) holds a cell is now a small pass of its own, a texel a cell of each snapping grid, and the glyph pass reads one texel a grid where every pixel used to make 16 mask reads. The pictures are the same to the byte. On DX12 with FXC (`WGPU_DX12_COMPILER=fxc`, and every game that doesn't ship DXC) the glyph shader's two entry points compiled in 10.5 s in a debug build and 7.2 s in a release build; they now take 0.9 s and 1.6 s, so the first ASCII frame no longer stalls. A frame whose snapping grids would need more than 8192 rows of the new state draws the variants past them cut to the pixel and says so once (`rows of snap owner state`).
**What to do.** Nothing.
