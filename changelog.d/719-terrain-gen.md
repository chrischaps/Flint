### `flint gen x.terrain.toml` bakes a terrain spec with no window, and the editor's heightmap export is fixed (#719)
**What changed.** `flint gen` takes a `.terrain.toml` and writes its 16-bit heightmap and RGBA splat map, the same bytes every run for a seed (`-o terrain/meadow.png` puts `meadow_splat.png` beside it; `-o terrain/` names both after `[meta] name`). It takes `-o`, `--seed`, `--strict`, `--dry-run` and `--json`, and warns about any spec key nothing reads, naming the key it probably meant. The terrain editor's Ctrl+E export used to write heightmaps with every 16-bit sample byte-swapped, so they read back as static. It now writes what `flint gen` writes. Baking a spec is also about 40 times faster, in the editor too, with the same output.
**What to do.** Re-export any heightmap you saved from `flint edit x.terrain.toml`, or run `flint gen x.terrain.toml -o <dir>/`. Fix the keys the new warnings name.
