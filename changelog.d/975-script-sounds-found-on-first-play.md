### `play_sound` finds a sound nobody preloaded, and `flint check` holds script sounds to that search (#975)
**What changed.** A sound name a script plays that nothing cached (no `audio_source.file`, not a file of an `audio/` the scene sees) is now looked for on its first play as an `audio_source.file` is: a path from the scene's folder or any folder above it up to the project root, then each `audio/`, then the engine's. So `play_sound("../sfx/door.ogg")` plays, where it used to warn "Sound not cached", and with `preload_audio = false` a script's sounds still play, loaded when first asked for (a large one misses that first play). `flint check` now holds a script's sound strings to that same search, so it reports what the player can't find: a sound beside the script, or in `models/` or another asset folder, used to pass and never played, and is now a `missing-file` error with the paths tried.
**What to do.** Run `flint check`. Move or rename any sound it reports, or write it as a path from the scene. A copy kept in `audio/` only so a script's written path would play can go, if the file it copies is inside the game: a web bundle packs the game's folder, not one outside it.
